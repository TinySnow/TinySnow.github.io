+# 年轻的女子
+
+*川端康成*
+
+　　年轻的女子带来的小说中，自传性的作品居多。一般说来，妇女都是先以描写自己作为其文学生活的起点。我读了这些作品，第一印象是，要真正述说自我，就是说要很好了解自我，彻底地辨别自我，这是多么困难的事啊。
+
+　　我把作为作者的她，同作品人物的她相对照，毕竟无法相信是同一个人物。原来这女子是这样考虑自己的吗？这是意外的印象，我为之所动。人虽不可貌相，可她也过分扭曲地来看待自己了。在明显的情况下，纵令她的小说把自己写成一个乐观开朗的人，而我得到的印象却是：她很悲惨。例如她像个胆小的天使，却在小说里把自己描绘成大胆的妖魔，把自己平凡的嘴唇描绘成充满美丽的柔唇。如果说从女人的虚荣心出发，把自己在文学作品中自我打扮一番那还算好，可是在许多情况下，她似乎确信她自己具备情人所说的一切。换句话说，在看待自我的时候，她们就不带自己的目光。
+
+　　当然，对于自古以来的大诗人来说，恋爱就是一种情人眼里出西施的错觉。诗人们及其不值一提的情人们都已经从这块土地上消失，只留下美好的作品，对于他们和我们的所有读者来说，这是无上的荣幸。让读者看到文学作品的模特儿，读者不感到幻灭是罕见的。依作者的看法，把实有的情人艺术化了的作品，无非就是梦想家的热情的错觉造成的悲剧。但是，优秀的艺术家，同我所认识的爱好文学的少女，是存在根本的不同的。他们用自己的眼光看待少女，而少女却用他人的眼光看待她们自己。
+
+　　常言道，丑妇和处女只了解一半人生。相反要说美女和主妇也只了解一半人生，这倒也是事实吧。一般来说，男性文学家即使没有经历过人世间的辛酸，光凭在书斋里的辛勤笔耕，随着年龄的增长也能逐步了解自己。能够在作品里把自己的心绪表现出来的女性文学家，大体仅限于那些有好几个情人的女子。也就是说，得用几个情人的眼光来观察自己之后才行，不然，女子光凭自己的眼光似乎是不可能看清自己的。
+

+
+　　1932 年 2 月

+# 百分比说得再准，也得先问分母是谁
+
+<!-- daily-essay-id: 2026-11-12 -->
+
+<!-- wechat-digest: 一个百分比能说明多少，要看它把哪些人算进分母，又遗漏了谁；把实际人数、回应范围和结论放在一起，既能保留已有反馈的价值，也能看清还有哪些人的情况尚未了解。 -->
+
+　　“满意率百分之八十”，听起来像是大多数人都觉得不错。
+
+　　但我想先问一句：谁里面的百分之八十？
+
+　　假设你组织了一场一百人参加的活动，结束后给每个人发了一份问卷。最后收到十个人的回复，其中八个人选择满意，两个人选择不满意。
+
+　　八除以十，百分之八十，计算完全正确。
+
+　　可写成“参加活动的人，八成满意”，问题就来了。你手里有十个人的回答，那句话却顺手把剩下九十个人也带了进去。
+
+　　数字算对了，主语变了。
+
+　　**回复的人，与参加的人，是两群范围不同的人。** 把前面几个字省掉，结论就比实际知道的事情大了一圈。
+
+　　这时候很容易走向另一边：总共一百个人，只有八个人明确说满意，那满意率岂不是只有百分之八？
+
+　　同样得把话说完整。在全部参与者中，目前收到的明确满意回复占百分之八，可以这样算；要说只有百分之八的人满意，仍然缺了其余那些人的回答。
+
+　　没回复的人里，可能有人很满意，只是回家后忘了填。也可能有人觉得一般，懒得再花时间；还有人压根儿没看见那条消息。
+
+　　这些都是可能，眼下还分不清各有多少。沉默既不能自动填进满意，也不能自动填进不满意。
+
+　　如果要如实说清这次反馈，最直接的写法就是：“一百人参加，十人回复，其中八人满意、两人不满意。”
+
+　　句子长了一点，却让读的人看得见，哪些地方有答案，哪些地方还空着。
+
+　　百分比本来很方便。不同数量的东西放到一起，换成同一个尺度，就容易比较。但在换算的时候，原来的规模和范围也容易从眼前消失。
+
+　　十份回复中的八份满意，写成百分之八十，也不会凭空多出几十份回答。后面添几位小数，更不能替缺席的人补上声音。
+
+　　我觉得，看这种数字时，先把它还原成人数，是个挺有用的习惯。到底多少个人，里面有多少人符合这句话说的情况，能说清这两项，讨论就有了落脚处。
+
+　　接着还可以看，回答是怎么收上来的。
+
+　　如果活动结束时，只请留下来聊天的几个人填问卷，那提前离场的人就没有进入这份记录。提前走究竟是赶车，还是对活动有意见，仍然要另外了解。
+
+　　问卷里没有他们的声音，不能靠猜测补齐。至少在介绍结果时，应该把“留到最后并填写问卷的人”这个范围保留下来。
+
+　　范围一旦明确，这八份满意的反馈依然有用。可以看看他们喜欢的是哪一部分，哪些安排值得继续做；那两份不满意，也可以指出下次要调整的具体问题。
+
+　　**知道一份反馈代表到哪里，才能决定拿它做多大的事。**
+
+　　想修改一处签到指引，看到有人明确说找不到入口，就有理由检查一下。想据此宣布所有人都希望再办一次，手里的信息就还差得远。
+
+　　问题的大小不同，需要弄清楚的范围也跟着不同。
+
+　　再设想下一次活动，仍然有一百人参加，这回二十人回复，十四人满意，六人不满意。回复者中的满意比例变成了百分之七十，比上一次低。
+
+　　同时，明确满意的回复从八份增加到了十四份。两个数字都是真的，单挑其中一个，就可以把汇报写成两种味道。
+
+　　要判断活动体验是否改善，还得看这次回应的是什么人、问的是不是同一个问题，以及具体意见发生了什么变化。把两次的回复数和内容放在旁边，至少比只盯着一个涨跌箭头清楚。
+
+　　这些追问也适用于自己喜欢的结果。看到一个百分比刚好支持原先的想法，最容易直接拿来用，连前面的限定都觉得碍眼。
+
+　　转述时把限定留下，观点可能没那么响亮，却更容易经得住下一句询问。对方知道你讲的是十份反馈，也就能继续问，另外九十个人有没有办法再了解一点。
+
+　　于是下一步可能很普通：把问卷入口发清楚，在方便的时候补问几位参与者，再把新收到的回答加入记录。收到多少就写多少，仍然没有答案的部分也继续留着。
+
+　　下次看见“八成人都赞成”，可以先把“人”前面省掉的那几个字找回来。
+
+　　是参加的人，回复的人，还是某个群里刚好投了票的人？分母说清楚以后，再谈那个百分比说明了什么。
+
+<br />
+
+　　南国微雪 Miyuki
+

+# 如果香港会死
+
+*林夕*
+
+　　上海会拥有中国境内第二个迪斯尼乐园，且必然比香港大上几倍，这该不是什么国家机密吧。如果对香港来说那是一个噩耗，民间应该早有心理准备，政府该有策略应对。为什么这事先张扬的消息一出，还是有报章用上“香港玩完”来形容区区一个乐园的影响力？
+
+　　如果香港将会玩完，也不会死于迪斯尼之手，更不会因为那批见大买大、见异思迁的内地游客而寿终正寝。香港迪斯尼自二零零五年开业以来，入场人数已屡创新低，既然没有对旅游业帮上过什么忙，捅穿了天，屋再多漏些连夜雨，也不会致命。要命的不是上海，是本地客占四成、内地客占三成的比例。
+
+　　作为陈年支柱的旅游业，竟然落得成也迪斯尼，败也迪斯尼，那这个城市本身的吸引力就大有问题，发展旅游业的策略眼光，也早在人家开张大吉前已出了状况。
+

+# 还要不要排队，得从现在往后算
+
+<!-- daily-essay-id: 2026-11-11 -->
+
+<!-- wechat-digest: 已经花掉的等待时间很难追回，是否继续应结合眼下的位置、剩余等待和其他安排重新判断；把过去的付出与当下仍有的选择分开，才容易看清接下来的时间愿意用在哪里。 -->

+　　“都排了半小时了，现在走岂不是白排？”
+
+　　这句话很有说服力，尤其对已经饿了半小时的人。可再站一会儿，前面仍然没动，问题又来了：现在排了四十分钟，是不是更该留下？
+
+　　照这个道理，越等越难走。至于还要等多久、接下来准备做什么，反倒被挤到了后面。
+
+　　假设你和朋友下午出来逛街，原本打算吃完饭，再去附近的书店。看见一家想尝尝的店，问了问，说大概二十分钟能轮到，于是拿了号。
+
+　　半小时过去，前面还有几桌。再问，回答是可能还得半小时。
+
+　　这时手里有了新的情况。原先预想的一顿饭，已经变成了另一种时间安排。继续等，吃完也许只能直接回去；换个地方，或许还能留出逛书店的时间。
+
+　　要决定的，就是这两个接下来的下午，自己更想过哪一个。
+
+　　**前面那半小时，留在原地也拿不回来。能决定怎么花的，是后面的时间。**
+
+　　真要走的时候，那点不甘心还是会冒出来。已经站了这么久，最后连味道都没尝到，似乎总得吃上这一口，才能给等待一个交代。
+

+

+

+
+　　反过来，同伴已经累了，或者后面有约定的事情，就得把这些情况放进决定里。一句“来都来了”，很难替所有人同时答应再站半小时。
+
+　　可以在拿号时先商量一个愿意等待的范围。比如最多等到两点，到时还没轮到，就重新看看剩余安排。提前说好，至少到了那个时候，大家都有一个共同的话头。
+
+　　这个时间也可以根据新情况调整。到点时已经在领位，和到点时队伍仍然没动，显然值得分别判断。上限的用处，是提醒人停下来重新看一眼。
+
+　　有人会说，走了以后万一马上就轮到了呢？确实可能。
+
+　　可当时作决定，手里有的就是当时那些信息。能问清剩余时间，选择就容易一点；问不到，也只能结合现有情况判断。后来碰巧发生的事，可以补充经验，却无法提前出现在手机里。
+
+　　走出那条队伍以后，剩下的下午还可以认真安排。去书店翻翻原本想看的书，找个地方吃饭，聊完刚才还没聊完的话题。
+
+　　下次再遇到“都等这么久了”，可以往后接一句：“从现在开始，咱们还愿意拿多少时间来等？”
+
+　　把这一句说清楚，再决定留着号码继续等，还是告诉店员取消等位，换个地方吃饭。
+

+
+<!-- daily-essay-id: 2026-11-10 -->
+
+<!-- wechat-digest: 礼物进入别人的生活，可能会有与送礼人设想不同的用法；认真感谢可以留住心意，把摆放、使用和调整的余地交给收礼的人，则能让这份心意少一些附带的负担。 -->

+　　送朋友一个杯子，后来发现他拿来插花，我觉得这杯子也算送对了。
+
+　　你买的时候，想的是他每天早上用它喝水。到了他家，杯子摆在窗边，里面插着几枝花。他喜欢那个颜色，只是更习惯用另一个大杯子喝水。
+
+　　东西确实融进了他的生活，走的却是另一条路。
+
+　　这时候如果问“怎么没拿来喝水”，朋友可能还愿意讲讲自己的习惯。再追问几次“这么好的杯子，拿来插花多可惜”，一份礼物就渐渐附上了使用说明，而且执行情况似乎还要接受检查。
+
+　　杯子在他家，怎么用的决定却还留在你手里。
+
+　　**既然是想让对方高兴，礼物到了他那里，就该有一点按他的生活重新安排的余地。**
+
+　　买礼物时，人很容易把一整幅画面都想好。送一本书，就想象朋友读完以后跟自己聊；送一个手账本，就想象他拿来记每天的生活；送一套茶具，就想象几个人以后坐在一起喝茶。
+
+　　这些想象可以是挑选时的乐趣。可真正收下礼物的人，还有自己的时间、空间和习惯。
+
+　　他可能正在读另外一本书，也可能更喜欢在手机上记事。茶具好看，但家里那张小桌子平时还要吃饭，只能先收进柜子里。
+
+　　礼物能不能照着想象使用，得跟这些事情一起商量。付款时的那一刻，并没有替朋友腾出读书的晚上，也没有让他家多出一张桌子。
+
+　　所以，“我花了这么多心思”，可以解释自己的期待有多大，却很难直接说明对方接下来该怎样生活。
+
+　　期待落空会失落，这很正常。认真挑了颜色，问过尺寸，甚至亲手做了很久，当然希望对方喜欢。
+
+　　但可以先分清，自己究竟在等什么。想知道心意有没有被收到，一句认真道谢、一次具体的回应，就能带来答案；想让礼物始终出现在对方生活的显眼位置，那已经是一个持续的要求。
+
+　　朋友收到围巾，说这个颜色挑得真好，出门时却仍然戴旧的那条，也可能只是旧围巾更厚，或是当天穿的外套更适合它。
+
+　　每次见面都检查围巾有没有戴，慢慢地，朋友出门前要考虑的就会多出一项：今天会见到谁，该拿哪件礼物出来。
+
+　　送礼原本想表达亲近，最后却让对方多做了一道准备工作。
+
+　　我更愿意在挑礼物的时候，把可能不合适的地方留得宽一点。尺寸拿不准就先问，拿得准也可以把换货的凭据留好，让对方知道可以换成合用的。
+
+　　问清楚会少一点拆包装时的惊喜，却可能多一点后来每天用得顺手的高兴。两种高兴，都值得考虑。
+
+　　尤其那些需要长期照顾、占很大地方的东西，更适合提前确认。自己觉得一大盆植物能让房间好看，对方可能连窗台都已经放满了。
+
+　　如果还得让他重新安排房间、研究怎么照顾，这份礼物里面，就已经包含了一项新的家务。先问清楚，才知道他有没有兴趣接下这件事。
+
+　　**送礼人的体贴，也包括允许自己的判断有偏差。**
+
+　　朋友发现尺寸不合适，愿意直接说出来，你就还有机会帮他换。要是每次听到这种反馈都受伤，他下次可能只会说喜欢，然后把东西收起来，再为收起来找一个更好听的理由。
+
+　　两个人都花了心思，只是用在了维持礼物很成功的样子上。
+
+　　收礼的一方，同样可以认真回应那份心意。说说自己看见的细节，感谢对方记得自己的喜好；拿不准会怎么用的时候，把话留在当下，也更诚实。
+
+　　“这个图案我很喜欢”，已经是一句完整的喜欢。顺口加上“以后天天都用”，却可能让双方开始期待一件自己还没想好的事。
+
+　　有些礼物确实承载着更特别的意思，比如亲手制作的纪念品，或者希望对方替自己留存的旧物。如果很在意它接下来怎样被保存，就提前把这层意思讲出来，让对方知道收下的是什么。
+
+　　对方愿意承担这份托付，双方就按说好的来。把特殊期待一直藏着，等看见东西被换了位置才生气，对方连判断的机会都没有。
+
+　　至于普通的日常礼物，过了一阵子不再合用，也可以让它有后续的去处。一个杯子陪过一段日子，后来闲下来了，这段陪伴仍然发生过。
+
+　　下次到朋友家，看见那个杯子插着花，可以问问花是在哪里买的。对方也许会告诉你，正好觉得这只杯子的颜色很搭，就把它放在了这里。
+
+　　这也是礼物被喜欢的一种样子。

+

+# 《入殓师》影评
+
+## 正文
+
+　　前阵子看完了近期挺出名的《入殓师》，一部日本片子。
+
+　　去搜了一下，才知道这片子在零八年就已经出来了。不知道为什么近期又上映了。我是随着大流去看的，事实证明，大流的东西不一定适合自己。
+
+　　这篇影评可能更多倾向于批判性。
+
+　　首先，日剧日片不得不品尝的一大特色——大喊大叫，反应过激。
+
+　　在这部电影里面很奇妙，不仅有这个现象，而且还有另一个极端。有的角色表情动作都僵硬，然后又有另一些角色，表情动作又极其柔和。两派演员混杂在一起，形成了一种微妙的观影体验。
+
+　　我一直觉得日剧的这种特色是他们的社会氛围导致的。压抑了许多的情绪，但又在日常生活中无法得到释放，于是假借着拍电影这一名号，大声呵斥或者疾呼，开启洪流的闸门。
+
+　　“毕竟是拍电影嘛。”
+
+　　我只能说不论是这种行为还是这种想法，都很日本。当然这些只是我的猜测。
+
+　　男主角的表情很丰富。有时候僵硬得很丰富（笑。
+
+　　我挺喜欢女主，但是剧中是一个典型的日本温婉女性形象，附和男主人。很多决定是男主角做，然后女主只是跟在一旁，任劳任怨。说实话，看得我自己有点不太舒服。直到后半段她任性地提出男主辞掉入殓师的工作时，我才觉得她正常而鲜活。
+
+　　其次，情节设计有待商榷。
+
+　　有很多情节可以采用更完美的设计，但依旧采取了感官最坏和最尴尬的那种形式。
+
+　　“你不好好读书，以后就只能跟他一样，你想一辈子做那种工作吗？”
+
+　　这句话不是指的清洁工，也不是售货员，在剧中指向了男主。我觉得这很奇妙。一方面，我们有求于入殓师，一方面又觉得入殓师不干净。跟那些医闹的人一样，令人丧气又觉得不可理喻。
+
+　　在剧中，这种情节俯拾即是，例如我从来没见过在葬礼上能相互指责甚至大打出手的人。
+
+　　再次，感情变化毫无征兆。
+
+　　不管是男主对于入殓师这份工作从抗拒到接受，还是女主对于男主从事这份工作从反感到理解，其中都没有太明显的变化。“润物细无声”不应该在这种片子当中出现。
+
+　　其他变化都挺明显，例如男主从助手到独当一面，变化都有迹可循，但我不明白，为什么暗线处理不好。并且在暗线没有处理好的同时，它想表达的东西又很多，例如家庭关系，例如生命的死亡与传承，例如隐瞒。这些话题单拿一个出来都能拍一部电影，但是它选择了在一部电影里面表述所有，但又做不到百科全书式的诠释，于是看起来抓不住重点，中心混乱。
+
+　　最后，我想单说一说男主的性格。关于隐瞒。
+
+　　这种隐瞒并非私藏自己的秘密，而是涉及两个人的生活。无论如何都应该拿出来斟酌的事情，男主角却因为觉得会遭受反对而隐瞒。这种行径说实话挺恶劣。
+
+　　信任，就是在一次次的危机与失望中下坠并破裂。
+
+　　“我要是说出来的话，你肯定会反对。”
+
+　　“那是当然的啊，但是你为什么还是不跟我说呢？”
+
+　　我为妻子心寒。
+
+　　无名指上的闪光，除了声明一份归属以外，更承担一种责任。这份责任，在漫长且只属于两个人的生活中，尤为重要。正因如此，在指根没有闪光的那些人看来，它同归属一样令人羡慕，它是一种承诺，还有保证。
+
+　　希望你们能够将承诺履行到底。
+
+　　当然这部片子还是有许多可取之处。里面充满了恰到好处的温柔与暖意，刚好让人觉得不那么矫情。很多来自日本的作品把握不好这个尺度，而它做得就比较好。
+
+　　我在看这部片子之前问我室友，觉得怎么样。他说，挺感人的。
+
+　　但我觉得在这一点上，仍然有进步空间。它给我带来的触动甚至不如《你好，李焕英》。
+
+　　满分五分，打个三分吧。
+

+# 随记 - 我会做菜了，可你在哪儿呢？
+
+## 写在前面
+
+<p style="color:#0f4c81; text-align:center; font-weight:bold; font-size:larger;">1608 字 | 想法 | 感触 | 生活 | 饮食</p>
+
+## 正文
+
+　　中午做饭。翻开冰箱，急冻室，里面还有一块上次去猪肉铺买回来的肉。买了一斤，当时只切了一半，剩下半块扔里面了。
+
+　　当时母亲说，做菜的时候提前给她打视频。
+
+　　母亲知道那个时候是我第一次做荤菜，从头开始做——不是直接把码好的肉和配菜一起倒进去炒熟那种。肉，要自己切、自己码。
+
+　　我也不知道当时脑子怎么抽了，要买块生肉。
+
+　　做的过程还算顺利，就是芹菜和青椒都买多了，炒了一锅，吃了有两三天才吃完，还有就是第一次切肉，没什么经验，肉丝切得有些厚。
+
+　　今天翻箱倒柜找食材，看见了剩下的半块，才意识到差点都忘了。
+
+　　我拿起它，犹豫了半晌。
+
+　　刹那间，我忽然想起大三的那个中午。
+
+　　当时我正上完课放学，她忽然打来电话，声音里带一丝慵懒。她说，在哪附近吃了一家很好吃的店，朋友推荐，她今天去试了一下，感觉还行，但没有家里的好吃。
+
+　　还说，她有些想念家里的味道。
+
+　　我当时也是脑子进水，笑了笑，跟她说：“你想吃什么嘛，我给你做。”
+
+　　我能很明显感受到电话那一头，直接愣住了。
+
+　　“嗯……嗯？”
+
+　　沉默了一秒钟，她开始笑：“你做不出来，”旋即又补充了一句，“很特殊的味道。”
+
+　　我也开始跟着笑。
+
+　　说这些话的时候，我正随着人流走。这所设施老旧的大学，仍用钟鼎敲响的声音作上下课的钟声，声音悠扬又古老。钟声随着周围学生的嬉笑打闹声穿过我，穿过电话。我抬头看了看高耸的第十教学楼，有树叶遮挡，只能通过罅隙看见建筑的顶端和天上的云。我的手捏着电话，放在耳边，就在川流不息的人群中驻足而立，看着天，说了后一句话：“万一我做出来的味道也很特殊呢？”
+
+　　两边都笑。
+
+　　“是好的那种就行。”
+
+　　“那肯定。”
+
+　　“下次试试吧。”
+
+　　“嗯，好。”
+
+　　她不知道的是，电话这边的这个男生，小时候因为做砸过一次荤菜，浪费了一锅肉，从此对做荤菜有着极大的心理阴影。此后几乎没有再做过荤菜，最多烧烧汤，做一做素菜。
+
+　　我不知道我出于什么动机，当时逞强说了那句话。
+
+　　就像延时摄影里那些不变的主角与风景，当时的我，站在人来人往的树下，还认认真真思考，之后该怎么办。都已经这样打脸充胖子了。
+
+　　母亲指导我怎样切肉、倒入香辛料、码肉的那个下午，我并未想太多。或许是因为没等我准备好，母亲的视频就提前打来了，也或许，是因为没有空思考，赶时间。而今天是周末。
+
+　　回过神来，我已经成功了一次了。而且，没有丝毫心理压力，只是一步一步地跟着母亲的指导。
+
+　　我没想到有这么简单。
+
+　　红油、胡椒粉、花椒粉、葱姜蒜末、干花椒碎、生抽、芡粉、料酒、豆瓣酱和醋。
+
+　　当时我还和母亲笑说，我可全听你的了，我觉得最难的就是这里了。
+
+　　我至今都不知道，母亲怎么隔着屏幕就能知道，哪些香辛料放多少，然后喊停。
+
+　　末了，她还说：“如果你想吃麻一点的，可以再倒点花椒油。”
+
+　　我没听，我说，等快出锅的时候再看看吧。
+
+　　“不放盐吗？”
+
+　　“出国的时候淡了再放，豆瓣酱已经有盐了，码肉的时候再放就咸了，腌进肉里之后还救不回来。”
+
+　　之后，我在家里又看了一遍。母亲按她自己的习惯，倒了哪些香辛料，倒多少。下过的时候，她把锅铲交给我，自己又去菜板上备其他菜。
+
+　　快出锅时，母亲又让我尝一下，看看少不少什么调料。我说，好像花椒味道好像淡了点。
+
+　　旋即，母亲又放了点。放的过程中，我一直在说，会不会太多了，会不会太多了。
+
+　　母亲却一直说，花椒面嘛，多放点无所谓，本来味道就不是很大。
+
+　　结果——麻得要死。
+
+　　那一锅肉，是母亲为我炒的，怕我在单位里嫌麻烦懒得弄。她提前炒好，用袋子小袋分装，让我带上，冻急冻室里，想吃的时候拿一袋出来解冻，热热就能吃。
+
+　　我有一次自己炸土豆丝，想吃点麻的，正好油也少了些，就放了花椒油，结果不小心放多了，也麻得要死。
+
+　　我想着这些笑出声。
+
+　　笑着笑着，又把那半块肉放下了。
+
+　　我现在确实懒得弄。母亲确实有先见之明。
+
+　　我拿了一小袋麻得要死的肉末豌豆出来，打开，往锅里倒，开始热。
+
+　　我已经会做肉菜了，那么你现在在哪里呢？佳芯小姐。
+
+<br />

+# 随记 - 最后的狂欢
+
+## 写在前面
+
+<p style="color:#0f4c81; text-align:center; font-weight:bold; font-size:larger;">1157 字 | 挑战 | 感触 | 想法 | 思考 | 体验</p>
+
+## 正文
+
+　　准确地来说，这是近一段时间的感想。
+
+　　如果没记错的话，我的头发，应该在 7 月初就要剪掉了。那时候我应该会回归一个正常人（如果说现在是不正常的状态的话）。
+
+　　前两天，大学室友过来玩，他说，我相比大学里已经改变了很多，起码变得更加不在意别人的看法了。然后一边指了指我的头发。
+
+　　说实话，我记不太清了。我只记得大学里的我，十分阴暗与敏感，像是日漫里经典的刘海长过眼睛的路人甲男一样。
+
+　　我当时笑了笑，戏谑说：“多半跟客户对线对出来的。”
+
+　　其实也不止是客户了。
+
+　　在这件事上，有来自陌生人、领导、家里人的全面压力。尤其是今年打算学游泳，每次进男更衣室的时候，都有人用极其诡异的目光打量着我。虽然我无所谓，但次数多了确实有些烦。其他情况就不写了，以前写过很多次了。
+
+　　就这次留长发的最初目的来说，已经圆满达成了。
+
+　　而在这之前不久，差不多满两年，我就已经很想剪掉了。
+
+　　并非出于压力，只是因为它实在太麻烦了。
+
+　　洗头洗澡的时间延长、更衣室的眼光，睡觉时的翻身，打扫卫生时雄脱满地，以及跳舞时压到头发疼得龇牙咧嘴等等。
+
+　　我都数不清到底有多少次因为它而拖延了。
+
+　　“洗头吹头得花个十几二十分钟，好麻烦，再玩儿会儿吧。”
+
+　　但是有时，我又很享受它给我带来的感觉。
+
+　　跑步，在意什么东西而回头，侧发会跟着飘到眼前；低头，旁发环绕，如席如帘；狂风大作时，它随风而动。而冷暖则更不必提，只有对比反差才让人有更深刻的体会。
+
+　　这些体验都很新奇。之前从未体验过。说实话，我也很喜欢。
+
+　　很纠结。
+
+　　而最终，我还是选了回归。
+
+　　毕竟，最开始本就不准备让它成为一个常态。
+
+　　当初，我留头发的理由之一，是想理解对方。
+
+　　但现在——我不太想理解对方了。
+
+　　有过这样一次经历，就已经足够了。
+
+　　说来有些自私，这样做了之后，时间一长，我能感受到许多人觉得这似乎理所当然。然后，在这基础上，继续用之前的方式对待我。
+
+　　“自己先善待别人，然后希望别人用相同的方式善待我。”我当然知道这是一种绑架。
+
+　　绑架归绑架，谁又不希望自己被善待呢？站在道德制高点批判，是谁都会做的事情。
+
+　　而上面这种模式，总有一个人要先踏出一步，这个人，我不能指望别人，那就只有自己了。
+
+　　长久以来，我一直都这样想。
+
+　　没有换来对等的对待，没有收益。
+
+　　不过我想，从一开始就不应该期待有所谓的“收益”吧，毕竟人际关系并非投资。
+
+　　也许是工作耗费了我太多的心力，我已经无力维系这种模式了，不管出于什么原因，我决定进入低功耗模式。
+
+　　不再无谓地共情。不再自作多情。
+
+　　我不清楚做出这个决定是否正确，也不清楚它是否属于一时兴起。
+
+　　留给我的时间还有两个月。
+
+　　现在，确确实实，最后的狂欢。就像泰坦尼克号上，那三人最后的演奏一样。
+
+<br />
+
+　　当剪刀合上之后，我想，真正为自己而活，不寄希望于虚无缥缈的期待，也是另一种“留长发挑战”吧。
+
+<br />
+
+　　南国微雪 Miyuki
