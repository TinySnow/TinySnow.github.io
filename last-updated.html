+# 西红柿里的爱情
+
+*佚名*
+
+　　女人在厨房做饭，男人在客厅陪我下棋。
+
+　　女人喊：“你进来一下。”声音很大，语气却温柔。男人去了一趟厨房，只有几步远，用了一溜小跑。
+
+　　出来时，他拿着切开的西红柿，边咬边问我：“该轮到谁走棋了？”
+
+　　我问：“你喜欢吃生西红柿？”
+
+　　男人一边咬着西红柿，一边抬头瞅瞅厨房：“不太喜欢。”
+
+　　我继续问：“那她为什么喊你，还切了这么一大块？”
+
+　　“她以为我喜欢，”男人说，“刚结婚那阵子，家里穷，我又馋，每次炒西红柿，她都要切一块，塞在我的嘴里。那时，我爱吃，现在，我不太喜欢了。”
+
+　　“为什么不告诉她？”
+
+　　“为什么要告诉她呢？假如她知道，我一直不爱吃她切的西红柿，你想，她会不会很失望？”
+
+　　那盘棋，他赢了。冲着厨房，他扯开嗓子喊：“老婆，我赢了，吃了你的西红柿，我变得精力充沛、思维敏捷！”
+
+　　爱情需要表达，一起生活久了，爱情的表达就变成了一些鸡毛蒜皮的生活习惯。
+
+　　比如为爱人沏一杯热茶，给爱人掖好被角，跟爱人开一个小玩笑，往爱人嘴里塞一块西红柿。当然，茶可能烫了，被角可能没有掖的必要，玩笑可能稍显粗俗，或者西红柿的味道不好。
+
+　　但是，千万不要拒绝，因为你拒绝的，不是一个动作，而是爱情。
+
+　　那些握过手，唱过歌，流过泪，爱过的人。所谓曾经，就是幸福。

+# 每个临时任务，都该说清楚它准备挤掉哪一件事
+
+<!-- daily-essay-id: 2026-11-20 -->
+
+<!-- wechat-digest: 临时需求的成本从来存在，只是常被藏进加班和延误里。说清优先级与被推迟的事项，才能让新增工作真正被安排进去。 -->
+
+　　每个临时任务，都该说清楚它准备挤掉哪一件事。
+
+　　下午四点，领导发来一条消息：“这个客户明天要看，你顺手把方案再改一下。”
+
+　　“顺手”两个字很神奇。它把一份可能要花两小时的活，装成了在键盘上拨两下就能完成的小动作。
+
+　　接到消息的人当然会改。可他原本正在写的周报、约好的测试、晚上要交的材料，并没有因为新任务来了就自动消失。时间还是那几个小时，工作却凭空多了一层。
+
+　　最后常见的结果是：有人晚一点下班，把所有事都硬塞进去；或者原来的工作悄悄延后，等到第二天又收到一句“怎么还没好”。
+
+　　这时候大家容易把问题归到执行效率上。是不是做得太慢，是不是安排得不够紧凑。
+
+　　其实更早的一步已经出了问题：新任务进门时，没有人问它坐哪儿。
+
+　　**任何新增事项，都是在占用已经分配给别的事情的时间。**
+
+　　这个事实听起来平平无奇，却常常被“紧急”“帮个忙”“就改一下”盖住。大家只看见眼前那件要加进来的事，很少把它和被挤到后面的那件一起摆在桌上。
+
+　　就像把一只新箱子搬进塞满东西的房间。箱子确实能放进去，前提是先挪开点什么。若谁都不管挪走的是哪一件，最后就是门口越来越堵，所有人走路都得侧着身子。
+
+　　工作安排也是一样。
+
+## 先问一句：那原来的哪件往后放？
+
+　　这句话的用处，不在于和人争谁更重要，而在于让选择显形。
+
+　　比如一个同事正准备下午交的资料，突然被叫去做一页临时演示。可以直接回一句：“可以，我现在在处理下午五点的资料。这个演示如果优先，我就把资料改到明天上午发，您看哪个更合适？”
+
+　　这并不是推活。
+
+　　恰恰相反，这是把决定放回本来该决定的人手里。谁提出新需求，谁更清楚它的紧急程度，也更适合判断哪件旧事可以让位。
+
+　　有些领导会说：“都挺急的，你加把劲。”这句话也提供了一个信息：他选择把成本放到你的额外时间上。你可以衡量这份成本自己愿不愿意接；若确实要接，至少要知道今晚留下来是在换什么，而不是以为所有事情本来就该这样完成。
+
+　　团队里的临时需求尤其值得说清楚。产品说要加一项功能，设计说得补一张图，运营说活动今晚就得上。每个请求单独听都很合理，叠起来却可能把原定计划砸得七零八落。
+
+　　这时最有用的做法，通常不是开会列十条“提升效率”的口号，而是列出两个简单的问题：这件事最晚什么时候要？它进来之后，现有哪一项改时间、减范围，或者换人做？
+
+　　答案有时候是“原计划照常，新需求找额外资源”。这也可以，只要额外资源真有着落。答案也可能是“这周活动规模小一点，先把核心功能做完”。这种取舍听上去不够漂亮，通常比把所有承诺同时挂着更诚实。
+
+　　**优先级的意义，从来不是给每件事贴一个漂亮标签，而是决定资源先流到哪里。**
+
+　　生活里也有同样的情况。
+
+　　周末原本打算收拾房间、去看望父母、补一补工作上的材料。朋友临时约你帮忙搬家，你愿意去，完全没问题。但去了以后，至少得承认有一件原定的事会被推迟。把这个安排告诉相关的人，也比到晚上才发现自己失约要好。
+
+　　人有时候不愿意做这种取舍，是因为一旦说出“这个先不做”，就像承认自己能力有限。
+
+　　可能力有限本来就是所有安排的起点。每个人每天有多少小时，团队有多少人手，预算能买到多少资源，这些都是实实在在的边界。假装边界不存在，只会把选择拖到最后一分钟，再让最没话语权的人承担。
+
+　　当然，也有真正的突发事件。服务器出了故障、家里有人生病、关键客户临时改变约定，这些时候，原计划当然得靠后。没人会要求火警响了还继续把会议开完。
+
+　　但突发之后，仍然要补上那个问题：接下来哪件事怎么办？有人去处理火情，谁来通知等着结果的人；今天的任务被打断，明天怎么重新排。把后续接住，临时处理才算完整。
+
+　　下次有人给你加一件事，或者你准备把一件急事交给别人，可以少说一点“顺手”“尽快”“抓紧”，多说清楚它在队列里的位置。
+
+　　要它先走，就得给它腾出路。
+
+　　这不是降低效率，是让效率终于有了能落地的地方。
+

+
+　　南国微雪 Miyuki

+# 挤公共汽车的社会学
+
+*廖保平*
+
+　　挤公交车时我们会发现一种有趣的现象，挤上车之前，我们总是大喊大叫着让我们上车，大家往里挪一挪，里面还有空间。当挤上去以后，我们又开始讨厌别人再挤上来，我们会虚张声势地说，挤死人了，实在挪不动了，你们等下一辆车吧，极不情愿地挪动位置。
+
+　　我们上车之前与上车之后的变脸，其实无他，所处的位置不同，利益不同罢了，一旦自己占据了社会的有利地位，垄断了社会资源，混成了成功人士，爬进了精英圈子，就会本能地有一种抬高门槛，减少竞争，保护既得利益的冲动。
+
+　　只要我们细心观察一下社会就能从林林总总的现象中找到很多的例证。比如说官场里，甲官员觉得乙官员会对自己构成升迁的威胁，就会想方设法打压排斥对方。比如在经济领域，垄断企业害怕其他企业来分一杯羹，就会采取各种手段挤压对手。比如在文艺圈子，名导演、名作家对青年导演、青年作家的压制也不少见……这都是属于自己挤上了车，不希望别人再挤上来，抢自己的“空间”的思想，毕竟，与人争食，哪里比得上自己独食！
+

+

+# 问别人该不该做之前，先把自己能承受什么说清楚
+
+<!-- daily-essay-id: 2026-11-19 -->
+
+<!-- wechat-digest: 好建议要落在提问者的真实条件上。把目标、手里的缓冲和最在意的代价讲明白，别人给出的判断才有机会帮你做决定。 -->
+
+　　问别人该不该做之前，先把自己能承受什么说清楚。
+
+　　“我该不该辞职？”是很常见的问题。
+
+　　问的人可能讲了很多：领导难相处，项目乱，最近每天都不想起床。听的人也很容易跟着情绪走，劝他快跑，或者劝他先忍一忍。
+
+　　可同样一份工作，对两个人的答案可能完全不同。
+
+　　一个人有半年生活费，正在做的项目又让他看不到什么成长，手里还有几个愿意聊聊的机会；另一个人下个月要还贷款，家里正需要用钱，换一份工作也未必能解决眼前的矛盾。两个人都说“受不了了”，这句话后面放着的东西却不是一回事。
+
+　　前者离开，可能是在给自己腾地方；后者立刻离开，代价可能大到让原来的痛苦换一种形式继续出现。
+
+　　所以“该不该”这个问题，常常少了一半。
+
+　　少的那一半是：你准备拿什么来交换？
+
+　　**决定从来不是在两个选项里挑一个顺眼的，而是在一组代价里选自己愿意付的那份。**
+
+　　找工作是这样，买东西也是这样。
+
+　　有人问该不该买一台贵一点的电脑，只说自己看中了某个配置。朋友回答“早买早享受”或者“等等双十一”，都谈不上错。但他到底是每天靠它吃饭，还是偶尔打游戏？现有设备卡住的是哪一步？买完之后，接下来几个月还想花钱做什么？这些条件一换，建议就跟着换。
+
+　　有的人想省时间，愿意多花钱；有的人这两个月的现金流很紧，时间倒还宽裕。同一台电脑放在两个人手里，甚至可以是一件完全不同的东西。
+
+　　这不是让每次买东西都开一场风险评估会。生活已经够累了，买个鼠标还要写可行性报告，多少有点过分。
+
+　　只是当你真的拿不准、准备把决定交给别人帮忙看一眼时，给对方一点能下手的信息，会比只问“你觉得呢”有用得多。
+
+## 建议的价值，在于替你照亮盲区
+
+　　很多人问建议，心里其实已经有了答案，只是希望有人替自己盖个章。
+
+　　这很正常。做选择总有一点不安，尤其是那些一旦做了就很难回头的事。找人聊聊，听见另一个人说“我觉得可以”，会让人觉得脚底下多了一块板。
+
+　　但朋友没法替你踩那条路。
+
+　　他不知道你能接受多长时间没有收入，不知道你最怕失去的是稳定、体面还是一段关系，也不知道你说“我想换个环境”时，真正想换掉的是工作内容，还是某个具体的人。
+
+　　这些没有讲出来，他给出的往往只能是自己的生活答案。
+
+　　这也解释了为什么有些建议听着很有道理，落到自己身上却总觉得别扭。对方可能从自己的经验出发，说“年轻就该多试试”；你手头正好有一笔不能动的钱，或者你要照顾一个需要陪伴的家人。对方说得真诚，前提却没有落在你的生活里。
+
+　　比起问“你觉得我该不该辞职”，不如多补几句：“我手里有四个月的生活费，找新工作预计得花两三个月；我最想摆脱的是现在的加班节奏；收入可以降一点，但我希望周末能留出来。”
+
+　　这样一来，对方可以帮你看得更具体：四个月够不够缓冲，先找再走能不能把风险压低，所谓周末能留下来，在这个行业里到底有没有可能。
+
+　　他还是无法替你决定，却能指出你可能漏算的地方。
+
+　　**好的建议不是替人按下按钮，而是把按钮旁边的说明书翻出来。**
+
+　　当然，提条件也有一个容易走偏的地方：把每一个细节都堆上去，最后谁也看不见重点。
+
+　　说自己在意什么，够用就好。通常讲清三件事已经能让对话落地：你想得到什么，你目前有什么缓冲，你最怕付出什么代价。
+
+　　比如想学一个新技能，目标是转行还是单纯好奇？每周能挪出几个晚上？最担心的是花钱、花时间，还是学到一半发现不喜欢？这些答案摆出来，别人推荐课程、建议练法时，就能少一点空话。
+
+　　有时候，说着说着，提问的人自己也会发现答案。
+
+　　他原本以为自己在纠结“要不要报名”，讲完才发现真正担心的是付费以后没人监督；或者以为自己舍不得离职，后来发现舍不得的是同事和那点熟悉感。问题换了，下一步也会换。
+
+　　这就是找人聊的另一层作用：不是请对方替你负责，而是借他的提问，把自己没说清的部分说清。
+
+　　下次你准备问一句“我该不该”，可以先留半分钟，写下自己愿意得到什么，又愿意承担到哪里。再去找那个既了解你、也敢问你难题的人聊聊。
+
+　　最后做决定的还是你。但那时你拿在手里的，会是一张自己看得懂的价目表。
+

+# 把“有空再说”说出口，等于把这件事交给运气
+
+<!-- daily-essay-id: 2026-11-18 -->
+
+<!-- wechat-digest: “有空再说”听着体谅，常把双方都想做的事放进没有时间和动作的空格里；给它留一个下一步，才有机会真的发生。 -->
+
+　　把“有空再说”说出口，等于把这件事交给运气。
+
+　　很多约定就是这样消失的。
+
+　　两个朋友聊起一家想去的店，一个人说：“好啊，等有空一起去。”另一个人说：“行，最近忙完联系。”对话到这里气氛很好，谁也没有拒绝谁，甚至都真心觉得这件事不错。
+
+　　过两个月，其中一个人在社交平台看到那家店关门了，才想起这句话。
+
+　　这种遗憾很小，小到谁也没法怪谁。可类似的事情积起来，会让人产生一个错觉：自己明明有很多想做的事，生活里却总也没有空位。
+
+　　问题往往不在空位少，而在“有空”从来不是一个能抵达的时间。
+
+　　每个人都会忙。工作、家务、临时消息，像一把不断往桌上添的筹码。已经写在日程里的事有机会被看见，只有一句“以后”的事，往往会被新的、更具体的安排盖过去。
+
+　　**“有空”并不是一个时间点，它只是给未来留了一块没有边界的空地。**
+
+　　空地上什么都可以放，也就什么都放不稳。
+
+　　这不是说每个念头都得立刻敲定。朋友随口提起的展、偶然刷到的一本书、想学的一门课，都还只是兴趣。兴趣本来就可以先漂着，过几天忘了，也说明它当时的分量有限。
+
+　　但有些事情已经值得往前走一步了。比如你们都想见面，比如确实想把一份材料一起看完，比如有一件该处理的家事一直没人起头。这时候继续说“下次”，等于把主动权交给两个人日程表里恰好重叠的那一点偶然。
+
+　　而且，日程表自己很少产生交集。
+
+## 给模糊的愿望留一个小钩子
+
+　　真正有效的约定，未必一开始就要精确到周三晚上七点半。
+
+　　可以先把下一步说出来。
+
+　　“我这周加班多，下周二我问你哪天方便。”
+
+　　“这个月底前我要把报名信息看完，到时发给你，我们再决定去不去。”
+
+　　“我先问问家里那边的安排，周日晚上给你一个准话。”
+
+　　这几句话没有凭空变出时间，却让一件原本悬着的事有了下一次出现的机会。到了那个节点，哪怕最后决定放弃，也是一种清楚的结束；比起彼此都以为“总会约”的那种拖着，要轻松得多。
+
+　　有的人会担心，写得这么具体，会不会把一次普通邀约搞得像项目管理。确实，约杯咖啡还要拉表格，谁受得了。
+
+　　重点从来不是复杂，而是让其中一个人愿意承担“再提一次”的动作。
+
+　　约饭可以简单到：“这个周末我看看天气，周五找你。”等到了周五，如果两个人都累得只想躺着，那就痛快说这周先算了。一次没有成行的安排，通常不会伤感情；最磨人的是，双方反复留下一句温柔的“改天”，又在每一个改天各自失约。
+
+　　这和买东西时把商品放进购物车有点像。放进去以后，你下次打开页面还能看见它，才能决定买、删，或者等降价。若只是在刷到时心里说一句“回头看看”，信息流一翻页，连重新选择的机会都少了。
+
+　　生活里很多想法也需要这样一个购物车。它不是承诺一定实现，而是把“我曾经想要”放到一个以后还能碰到的地方。
+
+　　当然，钩子也得挂在够得着的位置。有人说“过阵子约”，过阵子又是一段新工作、新行程，还是没有任何动作。那就把时间缩短一点，或者直接承认：这件事目前还没有排进生活。
+
+　　承认这一点不丢人。
+
+　　人能真正放进一周的事情本来就有限。把十个愿望都叫作“马上要做”，最后只会给自己添十份没完成的负担。挑出其中一两个真的在意的，给它们一个具体的回头时间，已经很好了。
+
+　　还有一种情况更值得说清楚：你心里已经知道自己大概不会去，只是当下不想扫兴，才接一句“有空再说”。这样拖着，对方可能会一直留着期待，也可能为了等你推掉别的机会。
+
+　　这时候直接说“我最近大概排不出来，别等我”，反而更体面。对方可以另找人，也可以换一个计划。把选择留在他手里，往往比留下一个模糊的希望更照顾人。
+
+　　所以，下次聊到一件确实想做的事，别急着用“以后”把它收起来。问问自己：我愿意在什么时候再提一次？谁来提？这一步很小，却能把一段客套话变成一件有机会发生的事。
+
+　　想去的地方、想见的人、想开始的事，未必都要马上实现。
+
+　　给它留一个能回来找它的路口，就够了。
+
+<br />
+
+　　南国微雪 Miyuki
+
+　　2026 年 11 月 18 日

+
+*保罗·柯艾略*
+

+# 把问题发进群聊，不等于事情已经有人接住
+
+<!-- daily-essay-id: 2026-11-17 -->
+
+<!-- wechat-digest: 群聊很适合让信息被看见，却常把“有人知道”伪装成“有人负责”。把对象、动作和确认说清楚，事情才真正有了落点。 -->
+
+　　把问题发进群聊，不等于事情已经有人接住。
+
+　　这句话听着有点像废话，可许多事情就是这样悄悄丢掉的：下午两点，有人往工作群里发了一张报错截图，配上一句“这个谁看一下？”；晚上七点，另一位同事翻到那条消息，问：“后来好了没？”群里安静了一会儿，大家才发现，原来谁也没处理。
+
+　　消息明明被十几个人看过，甚至还有两三个“收到”。问题怎么还在？
+
+　　因为“看见”是一种状态，“接手”是另一种动作。群聊最擅长制造前一种。
+
+　　人多的时候，我们很容易把自己的注意力误当成集体的责任。尤其是那种模糊的求助：谁有空、谁懂、谁方便，句子里好像叫到了所有人，也等于没有叫到任何一个人。
+
+　　这有点像一间教室里有人突然晕倒。只有一个人在场时，大多数人会去找老师、打电话或者扶一下；围着一圈人时，反而常常多出几秒钟互相张望。每个人都以为，旁边总会有一个更合适的人先动。
+
+　　群聊里的“已读”也有这种效果。它让人心里多了一点踏实：这么多人都知道，总会有人管吧。
+
+　　可事情不会因为被更多人知道，就自动长出一个负责人。
+
+## 谁来做，和谁该知道，是两件事
+
+　　有些信息确实该放进群里。系统故障、临时变更、活动提醒，范围越大，越应该让相关的人早点知道。这里的群聊承担的是公告栏的角色。
+
+　　但公告栏只负责贴出来，不负责把事情做完。
+
+　　比如客户临时改了交付时间，把这个消息发到项目群很有必要；接下来还要有人评估影响、联系参与的人、回复客户。若消息只停在“客户改时间了，大家注意”，后面每个人理解到的优先级可能完全不同。有的人继续做原计划，有的人等别人安排，有的人以为负责人已经在处理。
+
+　　真正能推动事情的，是一句更具体的话：“小李，你先确认测试最晚什么时候结束；我今晚九点前根据结果回复客户。小王看一下设计稿能不能跟着挪。”
+
+　　这句话里有对象，有动作，也有时间。群里的其他人仍然知道发生了什么，但关键的那几个人已经知道，自己接到的是哪一段。
+
+　　有人会觉得这样点名太强势，像是在给人派活。可比起让一群人猜测“谁会处理”，把请求说清楚反而更公平。被点到的人可以直接说明手头情况，其他人也能据此补位，而不是到了最后才发现大家各自等了一下午。
+
+　　**责任模糊，表面上显得客气，实际最消耗协作。**
+
+　　这件事在生活里也一样。家族群里有人说“奶奶下周要复查，大家记得关心一下”，听上去很周全。可挂号谁办、哪天陪、检查资料在哪里，仍然悬着。每个人都可能在心里惦记，却没人知道下一步从哪里开始。
+
+　　把关心落成安排，并不会减少感情，反而让关心有了能抵达的地方。
+
+## 最后那句确认，才是交接
+
+　　很多群消息还有一个毛病：第一条说得很清楚，后面被别的话题冲走了。过了半天再回头找，发消息的人以为对方看到了，被提到的人以为自己只是被顺带告知。
+
+　　所以交办完事情，最好等一句明确的回应。
+
+　　“我来处理，六点前给结果。”这句话的价值不在于礼貌，而在于它把一个飘在群里的问题，变成了可以追踪的承诺。六点之后如果还没有结果，大家讨论的就是卡在什么地方，而不是重新猜一遍究竟谁负责。
+
+　　当然，群里也有真正需要大家一起想的难题。碰到方向不明、信息缺得多的情况，先把问题抛出来集思广益很合理。只是讨论结束时，总该有人把散开的意见收一收：我们决定先试哪条，谁去做，什么时候再碰一次。
+
+　　否则群聊会留下许多热闹的气泡：有人贴了链接，有人给了建议，有人说“这个可以”，最后没有任何一项变成下一步。
+
+　　下次你往群里发一件需要推进的事，可以在发送前多看一眼：这条消息是想让大家知道，还是想请某个人行动？若是后者，把名字、动作和时间写出来；收到回应后，再留下一句确认。
+
+　　群聊可以让消息抵达很多人。至于事情能不能抵达终点，还是得有人把它接在手里。
+
+<br />
+
+　　南国微雪 Miyuki
+
+　　2026 年 11 月 17 日

+# 我的死
+
+*刘亮程*
+
+　　那是一些等死的人。二十年前我离开黄沙梁时，他们已经闲坐在墙根晒太阳了。那时他们五十岁，或四十八九的样子，看上去不是太老。他们的儿女都已长大成人，接替了家里的事情。他们早早闲下来。每天太阳照东墙时他们在墙东边抽烟闲谝。太阳移到西墙时他们在墙西边打盹聊天。
+
+　　他们中间的几个人已经不见了。其他几个，从五十岁等六十，又从六十岁等到七十，死亡还没有来临。
+
+　　有时候他们好像等急了，站到路上望一阵子，又坐回到墙根里。
+

+

+

+

+

+

+
+　　我想像一只小虫一样在草根下简单地死去。
+
+　　我死了，我的躯体应该像一根木头留在村里。多少年后我转世回来，他还结结实实，担在谁家的圈棚、房顶上，或作为拴牛桩栽在院子，他古怪的横扫指着的地方，是谁家废弃经年的院子，门楼不见，墙垣塌斜。
+
+　　我一直在想办法弄清自己的死。
+
+　　我正一步步走近的那一场死亡或许不是我的。
+
+　　在那一刻我会看见我不认账的一个身体正渐渐死去。
+
+　　他挣扎着，蹬了一下腿。
+
+　　或许非常平静安详地——不动了。
+
+　　我也许不会按我想象的方式轻易死去。死亡不是我的敌人，不需要我用一生的欢乐与幸福去抵消对付它。
+

+
+　　这边，是打得干干净净的饱满麦粒。
+
+　　那边，是垛得高高的金色麦草垛。
+

+

+

+
+　　我二十岁那年的秋天，家里有过一次少有的大丰收。麦子打了 57 麻袋，苞谷棒子堆了一院子，还有黄豆、葵花、油菜……十几年来我们第一次感到仓房小了，麻袋不够用。到了下头场雪，没处安置的苞谷棒只好一摞摞码在房顶上，惹得各种各样的鸟一冬天在我们家房顶盘旋。那时候我想，要是再有几个这样的好年成，我们就能把一辈子的粮食全打够，剩下的年月可以啥也不干地坐在墙根。我三十岁的时候，已经离开村子在一个城郊乡当农机管理员，那时我幻想着，我顶多干到四十岁，把一辈子的钱挣够，尔后安安静静呆在家里。
+
+　　现在我已快四十岁了。我知道一生的许多想法都将一一落空。我根本无法在某个年龄停下来。即使到了六十岁，仍会有六十岁的一大堆事情——这时候我看见了那个让我最终停下来的终结——死亡。突然间我对这种一往直前的生存惊恐万分。我该早早地为我的死亡做点事情了。至少，我可以从从容容地晒着太阳，等候它的来临，像等候注定要来的一个友人。无论在黄沙梁的土墙根，或是城市街旁的石椅上，一个人只要消停下来，都会静静安安地等到自己的死亡。
+
+　　死亡来了，我们就跟着它去。
+
+　　我们向哪里去？当他们注销我的户籍、收回我的职务和土地、从各式各样的表格与名单中划去我的名字……我将去向何处。
+
+　　我相信在黄沙梁，那些早早停住地上的粗活闲下来的一双双手，已经在天上盖好房子。他们自己的房子。是否也像一个村庄一样。
+
+　　我在地上只有一个行将废失的家园。在天上我没有自己的一砖一瓦。我注定要四处漂流的魂魄只有你——黄沙梁，这唯一的去处与归宿。
+
+　　当我死去，我已经全部地归属于你。
+
+　　你能埋掉的，葬入你的黄土。
+
+　　你埋不住的，让它飘游于你的高远天际。与你的尘土、炊烟、树叶和草籽一起，一年一年地，起起落落。
+
+　　让它成为你下一个春天的种子。
+
+　　让它再发一次芽，再开一次花。
+
+　　让它在你一场一场的风中，再一次感知你的恩惠与生机。
+
+　　——我的黄沙梁啊！

+# 我是怎样自杀的？
+
+*阿吉兹·涅辛*
+
+　　报上刊登自杀的消息，通常是被禁止的，然而，下面要谈的是我个人的自杀问题，因此，我希望威严的官府，不仅能高抬贵手，准予报导，甚至还能为我这样一个无名小卒的自杀庆幸。我曾一度得了自杀狂症，心里总想着自杀。我的第一次自杀经过是这样的：“喂，朋友！”我自言自语道，“怎么个死法更好，用手枪，还是用匕首？”死么，都是一样的……但是至少让我死得高尚一些：我决定服毒自杀。我买了剧毒药品，将自己关在屋里，写了一封充满浪漫情调的长信，结尾写道：“永别了，空虚的人生，永别了，变幻莫测的命运，永别了，所有的一切……”然后，我服了一杯毒药就躺倒在地上。现在我的血管就要萎缩了，我的手脚就要抽搐，血液就要凝结。我这样等了又等，但什么事情也没有发生。于是，我再喝一杯毒药，接着又一杯……但是，毫无反应。后来，我恍然大悟：原来，在这个国家里，不仅牛奶掺水，油掺假，干酪掺假，就连毒药也是掺假的。因而，一个人随心所欲想采取一种自杀手段也是做不到的。而我个人，想到就要做到。这一次，我决定朝自己的头砰的一枪来了却我的残生。我把枪口对准太阳穴，扣动扳机：“卡——答！”又扣动了扳机：“卡——答！”再扣动了一次扳机：“卡——答答！”原来，这支枪是一批美国援助的武器中的一支，里面缺少零件。我看用枪弹结束自己生命已经不可能了。于是，我想到了保险的办法——用煤气来窒息自己。据说，煤气中毒致死是富有诗意的。我把煤气开足，并将屋里的所有缝隙都堵住了。我倒在椅子上，摆好了最合适的姿势，以便在人们找到我的尸体时能够保持肃穆的气氛，于是，等待着阿兹拉伊尔①来临。中午过去了，夜幕降临，我的呼吸怎么也不停止。晚上，我的一位朋友来找我。
+
+　　“不要进来！”我大声嚷道。
+
+　　“怎么啦？”
+
+　　“我正在死呢。”
+
+　　“你没有死，你是在发疯。”
+
+　　他说。我把自己的计划告诉了我的朋友。他捧腹大笑道：“你真蠢，从煤气阀门出来的不是煤气，而是空气。”
+
+　　说完，他又问我：“你真想自杀吗？”
+
+　　“当然是真的。”
+
+　　我答道。
+
+　　“我愿意助你一臂之力。”
+
+　　他说。接着，他建议我到制刀匠那里买一把布尔萨刀，然后像勇敢的日本武士那样切腹自尽，并让肚子里的肠子流到自己的手心里。我对我的朋友所表示的友谊和关怀表示感谢，并立即去买了一把布尔萨刀。老实说，用刀子一声地剖开自己的肚子，并不是一件好受的事。而且我觉得，当我的尸体被抬到停尸室里进行检验时，医生如果在我的肚子里看不到有任何食物，那可太难堪了。管它呢，我还是把刀子放进怀里，高高兴兴地跑回家去。正在这时，两个警察向我冲过来。于是，我向警察解释：“先生们，请等一下，先听我说。我老老实实地交纳税金，我从不说政府闲话。像我这样的老实人……”警察打断了我的话，并从我怀里搜出了那把刀子。
+
+　　“这是什么？”警察吼叫起来了。原来，我正好遇上这两个专管搜捕和制止犯罪活动的警察。
+
+　　“唉，我的真主啊！”我自言自语道，“我无法在这个国度里活下去，我作出自杀的决定，是最合适的。但是，你看，我也没办法离开这个尘世呵！……难道总是这样折磨下去吗？”我是有决心有意志的人，一旦说要死，我就一定要去死。我从杂货店老板处买了一条粗绳子，还有一块肥皂。我在绳子上涂抹了肥皂，系在天花板上的吊钩上。当时我的心情像是踏进税务局大门一样，把自己的脖子套在涂抹肥皂的绳子上，接着就一脚踢掉了椅子。可是，我并没有被吊起来，扑通一声，我跌落在地板上了。原来，绳子也是腐朽的。看来，我无法找到结实的绳子了。我得去找那位老板。店主说：“若是好货，我们还卖吗？”我完全明白了，自杀是无指望了。
+
+　　“算了，就这样活下去吧！”我自言自语道。众所周知，民以食为天。我特别爱吃腊肉煎鸡蛋。我在一家饭馆里，先吃腊肉煎鸡蛋、罐头橄榄油煎白菜卷以及一份通心粉；后到糖果店买四五块甜酥吃了。这时，一个卖报人走过来，喊道：“共十六版，你如不想看，可当包装纸用。”
+
+　　我没有读官方报纸的习惯，但是，这回，我对报贩说，我要一份。当然读社论时，我就朦胧地入睡了。突然，我感到腹部剧烈绞痛，似乎有人用刀子在我肚子里搅动。我无法形容疼痛的滋味……我实在受不了了，喊了起来。人们用急救车把我送进急诊医院。我已昏过去了。当我睁开眼睛的时候，一个医生站在我的身边，他问道：“你好像中毒了，你不能瞒着医生，你想自杀吧？”
+
+　　“说到哪里去了，医生，在这幸福的日子里，您说到哪里去了？”
+
+　　“你是中毒了，你吃了什么？” “腊肉。”
+
+　　“什么，吃了腊肉？”医生大声地说，“你疯了，腊肉能吃吗？难道没有看报？医院挤满了腊肉中毒患者。但是，你不像吃腊肉后中毒的人。你还吃了什么东西？”
+
+　　“我去过饭馆……”
+
+　　“你大概是疯了。”
+
+　　“在饭馆里吃了罐头。”
+
+　　“怪不得，还吃什么了？”
+
+　　“通心粉、甜酥……”
+
+　　“你当然要中毒了，罐头、通心粉、甜酥……”医生说。
+
+　　“除了这些，你还吃什么？”医生又问？“我向真主发誓，再没有吃别的东西了，只是在读官方报纸时……”
+
+　　“啊？”医生惊叫起来，“谢天谢地，你算是捡回了一条命！”出院时，我在想：算了吧，我们还能做什么呢？求生不得，欲死不能……我们只能无声无息地苟延残喘地活下去。
+
+　　注：①伊斯兰教中的死神。
