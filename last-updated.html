+*星新一*
+
+　　一个女人来到神经科医生那里。她三十上下岁，长相还算漂亮，但满面忧云，大约是源于内心极度的难言之苦。当然，假如没有什么苦恼，精神十分正常，谁也不会到这里来的。

+# 餐厅好不好，要看你准备在里面做什么
+
+<!-- daily-essay-id: 2026-11-26 -->
+
+<!-- wechat-digest: 选餐厅时，评分和菜式只是一部分。把这顿饭想完成的事放在前面，才能知道安静、距离、价格和座位到底该怎么取舍。 -->
+
+　　餐厅好不好，要看你准备在里面做什么。
+
+　　“附近有什么好吃的？”这句话常常把选餐厅变成一道很奇怪的题。
+
+　　有人给你发了评分最高的火锅店，有人推荐一家要排两小时的网红面馆，还有人说自己常去的咖啡厅最舒服。推荐都很真诚，放到同一顿饭里却未必能直接用。
+
+　　因为“吃饭”这两个字，后面可能跟着完全不同的事情。
+
+　　有的人下班路上饿得发晕，只想二十分钟内吃上一口热的；有的人隔了很久见朋友，想坐下来聊三个小时；有人要请客户，得让对方方便停车、说话听得清；有人带着长辈出门，菜单、楼梯和洗手间都比拍照好不好看重要。
+
+　　同一家店，在不同的晚上可以得到完全相反的评价。
+
+　　排队很久的店，也许值得专门来一次；刚开完会、还有半小时就要赶车的时候，它再好吃都容易让人烦。音乐很大的小酒馆，朋友生日时气氛很好；要认真谈一件事，可能一句话得说两遍。
+
+　　**餐厅的味道很重要，但一顿饭的用途，决定了什么叫合适。**
+
+　　这和挑一件衣服有点像。雨天穿的外套、面试穿的衬衫、周末散步穿的鞋子，未必由同一套标准选出来。把场景先说清楚，选择反而会简单很多。
+
+　　所以问别人推荐之前，不妨先补半句：“我想找个能聊天的地方”“我一个人想快点吃完”“我们带小孩，最好别等太久”。
+
+　　对方立刻就知道该从哪一类店里找。你拿到的也不再是一张“全城最好吃”的泛泛名单，而是一家适合今天的答案。
+
+## 一顿饭的附加条件，往往比菜单更早决定体验
+
+　　很多让人失望的聚餐，菜其实没有问题。
+
+　　比如约朋友庆祝生日，订了一家口碑很好的小馆子。到了才发现座位挤在过道边，上菜很快，桌子却小得连礼物都放不下；隔壁桌说话声不断飘过来，大家想讲句完整的话都得凑近。
+
+　　店还是那家好店，只是它没有完成这次聚会想要的事。
+
+　　再比如和很久没见的人吃饭。有人把地点定在自己常去的快餐店，价格实惠、出餐也快。两个人端着盘子坐下，半小时后店员开始收桌，话刚聊到一半就得起身。下次再见又不知道是什么时候，省下的那点钱和时间，未必比被打断的遗憾重要。
+
+　　当然，每顿饭都策划成活动方案，也太累了。
+
+　　平时一个人吃饭，能顺路、合口味、吃完舒服，已经很好。和熟人临时碰面，找一家随时能坐下的店，聊天自然比精心挑选更重要。
+
+　　只有当这顿饭承载了别的期待，才值得多看几眼菜单以外的东西。
+
+　　想聊天，就看座位间距、音乐和能坐多久；想庆祝，就看看能不能订位、有没有适合分享的菜；想让对方轻松一点，距离和交通往往比“这家必吃”更有分量；有人有忌口，就把菜单和过敏原提前确认。
+
+　　这些并不会让选择变得复杂。相反，它们帮你排掉了许多表面上很优秀、实际上不适合今天的选项。
+
+　　还有一种常见的误会：把自己喜欢的餐厅，直接等同于适合带所有人去的餐厅。
+
+　　你喜欢重口、热闹、排队时顺便刷手机；朋友可能胃口清淡、膝盖不舒服，或者只是今天没多少力气等。把自己的偏好说出来当然没问题，但替别人做决定之前，问一句“你今天想吃什么、方便等吗”，总能少一些互相迁就的疲惫。
+
+　　**请客的心意，也常常藏在你有没有把对方的实际情况放进选择里。**
+
+　　有些人特别爱说“都行”。这时候可以把问题缩小一点。给两个具体的选项：“一家近一点，安静，菜清淡；一家要走十分钟，烧烤更多。你今天更想哪个？”
+
+　　选择被缩小之后，对方更容易回答。即使他还是说都行，你也已经把判断所需的信息摆出来了，接下来按场景决定就好。
+
+　　吃完之后，下一次选择会更准确。朋友说“这家聊天挺舒服”，记住的就不只是菜名；长辈说“这里走路太远”，下回约饭时会自然避开。所谓会挑餐厅，很多时候就是慢慢记住了：谁在意什么，哪种场合需要什么。
+
+　　下次打开点评软件之前，先别急着看榜单。想一想今天这顿饭，除了填饱肚子，还想让它完成什么。
+
+　　答案有了，菜单之外的路也就清楚了。
+

+# 截图能说明一瞬间，链接才方便人把事做下去
+
+<!-- daily-essay-id: 2026-11-25 -->
+
+<!-- wechat-digest: 截图适合让人快速看见当时的画面，链接和出处才能让对方继续核对、操作和判断。把两样东西一起给，信息才真正方便流动。 -->
+
+　　截图能说明一瞬间，链接才方便人把事做下去。
+
+　　朋友在群里问：“这家店怎么样？”有人立刻发来一张评价页截图，星级、几条评论、几张菜的照片都在里面。
+
+　　看完以后，问题才刚开始。
+
+　　它离你多远？能不能订位？营业到几点？刚才那条差评是什么时候写的？截图里都看不清。你想自己搜，又得根据店名猜是哪个平台、哪一家分店。对方原本好心分享的信息，转了一圈，又变成新的搜索任务。
+
+　　类似的事情每天都在发生。
+
+　　有人转发一张商品页，问值不值得买；有人贴一张报错提示，说“这个怎么处理”；有人截了一段文章，表示“你看看这段”。画面确实来了，来源却留在了原来的页面。
+
+　　这不是截图不好用。截图很适合它擅长的事：把某个瞬间、某句重点、某个难以复现的画面递给别人看。它直观，打开就能看见，也不会让对方在一长页文字里找半天。
+
+　　可截图更像一张照片。
+
+　　照片能证明当时你看见了什么，却很难带人回到那个地方。
+
+　　**当信息会影响对方下一步行动时，出处本身也是信息的一部分。**
+
+　　发商品截图时附上链接，对方才能看尺寸、运费、退换规则和现在的价格；发一张活动海报时附上报名页，别人才能确认时间、地址和名额；发一个错误提示时说明软件版本、操作路径，接手的人才能知道从哪里开始找。
+
+　　截图负责让人迅速理解你在说什么，链接负责让他继续往下走。两样放在一起，才算把一件事交代完整。
+
+## 让信息能被别人接着用
+
+　　很多人省略链接，并不是故意给人添麻烦。
+
+　　手机里截图最顺手。看到有意思的内容，按两下就存好了；聊天时从相册里一发，也比回到原页面找分享按钮更快。尤其是已经翻过很多条内容之后，想再找回那个链接，自己也会觉得麻烦。
+
+　　可这点省下来的步骤，经常会被转移给收到信息的人。
+
+　　他得放大图片认店名，复制不出来的文字只能手打，担心截到的是过期活动，还得重新搜一遍。若这是一项需要多人确认的安排，后面每个人都可能重复做一次同样的查找。
+
+　　这就像你把一本书翻到某一页，递给朋友看其中一段。这个动作很好；若你把封面、书名和页码也告诉他，他之后想回去看前后文，才找得到路。
+
+　　所以分享时可以多问一句：对方看完这张图，下一步要做什么？
+
+　　如果只是想让他看一个好笑的瞬间，截图足够了。朋友发来一张路边写错字的招牌，谁也不会追问这家店的地图链接。
+
+　　如果是为了让他判断、购买、报名、处理问题，最好把能继续追溯的东西一起给出来。链接、原帖、文件名、地点，选其中最合适的一样就行。对方未必立刻点开，但需要的时候，入口还在。
+
+　　有些内容当然没有可分享的链接。私密聊天、内网页面、临时弹出的通知，截图可能就是唯一可用的方式。这种情况下，多补一句背景也能帮上忙：这是哪个应用、在哪个页面看到的、刚才做了什么操作。信息仍然能往后传。
+
+　　还有一种情况值得注意：截图会把当时的状态固定下来，链接打开时内容可能已经变了。
+
+　　价格会变，文章会修改，网页会下线。要是你想强调的正是“当时页面写了什么”，截图很有必要。把截图和链接一起发，对方既能看见当时的样子，也能知道现在页面走到了哪里。
+
+　　这比单独相信其中一个更稳妥。
+
+　　工作里尤其如此。有人把数据图截下来发进群里，大家围着图讨论半天，后来才发现取数日期不同；有人把一段文案截出来请改，改完以后找不到原文件，下一轮又要重新对照。
+
+　　图表旁边留一个文档地址，截图下面写一句版本和时间，后面接手的人就少走很多弯路。信息没有变多，只是把它从“看过”变成了“能用”。
+
+　　下次准备发截图时，可以顺手把原页面也分享出去。要是觉得链接太长，发在下一条消息里也行，再说一句自己想让对方看哪一处。
+
+　　一张图让人看见你看见的东西；一条来路，让人能走到同一个地方。
+
+<br />
+
+　　南国微雪 Miyuki
+
+　　2026 年 11 月 25 日

+# 留宿一晚，最该先问的是明天几点起床
+
+<!-- daily-essay-id: 2026-11-24 -->
+
+<!-- wechat-digest: 留宿看起来只是借一张床，实际会进入对方整晚和第二天的生活。把到达、离开和需要准备的事提前说清，彼此都能更自在。 -->
+
+　　留宿一晚，最该先问的是明天几点起床。
+
+　　朋友来一座城市玩，活动结束得晚，顺口说一句：“要不我今晚住你家，明天再走。”
+
+　　很多人会立刻答应。家里有地方，关系也不错，借住一晚而已，听上去没有什么大事。
+
+　　可人真正进了门，事情才开始变多。
+
+　　他几点到，要不要一起吃夜宵，能不能洗澡，毛巾和睡衣在哪里，行李放哪儿，早上谁先用卫生间，门锁怎么开，明天你几点出门，他几点离开。若住处本来就小，或者第二天还有工作，这些细节会直接占进原本属于主人的睡眠和早晨。
+
+　　客人可能完全没想到这些。他觉得自己只占一张沙发或一间空房；主人也觉得既然答应了，就该热情一点。于是一个人不断说“随便”，另一个人不断猜“这样会不会打扰”。
+
+　　最后两边都累。
+
+　　**留宿从来不是借一块平面，而是临时进入另一个人的生活节奏。**
+
+　　空床只是条件之一。真正要腾出来的，还有浴室的时间、屋里的安静、早晨的安排，以及主人下班以后那点本来可以完全属于自己的松弛。
+
+　　这不是说朋友之间就该算得很清。恰恰因为是朋友，才更适合把这些说出来。关系好的人，通常经得起一句“我明天七点得出门，你要是住的话，早上可能得跟着早起”。
+
+　　对方听完可以选择早点走、换一家酒店，或者说没关系我自己能安排。大家都知道实际情况，后面反而容易相处。
+
+## 先把时间表摊开，热情才有地方落
+
+　　如果你是想留宿的一方，开口时多给一点信息会很有用。
+
+　　比如：“演出大概十一点结束，我可能十二点左右到；明天十点前就走。你方便吗？要是明天有安排，我就订附近的地方。”
+
+　　这句话没有把压力藏在“我们这么熟”的默契里。主人知道自己要接住的是怎样的一晚，也拥有一个清楚回答方便或不方便的机会。
+
+　　有时主人家里确实不适合留人。合租室友早睡，有家人需要安静，宠物怕生，自己正好在赶一个早起的行程。这些理由都很正常。别人愿意提供住处是情分，住处的主人也有自己的边界。
+
+　　客人提前问，给的是选择；临出门才说“这么晚了我总不能回去吧”，给的就更像一道很难拒绝的题。
+
+　　而如果你是招待的一方，答应之后也可以把基本安排讲清楚。
+
+　　“我家洗澡热水慢，你到之前先说一声，我把毛巾找出来。”“我明天八点要线上开会，九点后你再起也行，门锁这样开。”“冰箱里有牛奶和面包，早上你饿了自己拿。”
+
+　　这些话看着琐碎，作用却很大。客人知道怎样行动，主人也少了半夜还要临时找东西、第二天怕吵醒对方的顾虑。
+
+　　尤其是第一次去朋友家住，问一句“有什么习惯要注意吗”，比到了现场再猜好得多。鞋子放哪里，室内温度如何，能不能抽烟，宠物喜欢怎样被接近，这些都没有标准答案。对方告诉你，是在分享自己的生活方式；你照顾到这些细节，也是在让下一次邀请更轻松。
+
+　　当然，临时遇到麻烦的人，情况另当别论。航班取消、深夜下大雨、身体突然不舒服，这些时候先让人有地方安顿下来最重要。等事情平稳一点，再慢慢商量后面的安排。
+
+　　只是大多数留宿并非突发。旅行、聚会、看演出，日期常常早就知道。提前几天把时间和需要说清楚，远比当天深夜一边客气一边为难更舒服。
+
+　　还有一个常被忽略的小事：第二天怎么离开。
+
+　　主人可能以为客人吃完早饭就走，客人以为可以待到下午再逛逛。两边谁也没说，到了中午就开始出现一种微妙的客气——主人在家里转来转去，客人也觉得自己是不是该走了。
+
+　　把离开的时间提前约好，彼此就少了靠察言观色来猜的负担。想多待一会儿，也可以直接问：“我下午两点的车，能在你这儿坐到一点吗？”对方答应得爽快，彼此都踏实。
+
+　　留宿本来是一件很温暖的事。有人愿意把自己的空间和夜晚分一点出来，有人愿意信任地把自己交到朋友的屋檐下。
+
+　　把时间表说清楚，不会冲淡这份温暖。它让热情少一点猜测，多一点可以真正落下来的安稳。
+
+<br />
+
+　　南国微雪 Miyuki

+　　把朋友带进陌生人群，邀请才算完成一半。
+
+　　有一种聚会，去之前觉得应该挺好，坐下十分钟以后开始看手机。
+
+　　朋友说：“今晚带你认识几个很好玩的人。”你答应了。到了餐厅，他和另外三个人一见面就聊起大学宿舍、上次旅行和某个你完全不知道的共同朋友。每个人都笑得很开心，你也能听出来他们关系很好。

+
+　　朋友偶尔回头问一句“你最近怎么样”，你刚说两句，旁边的人又接着讲起刚才那个旧话题。你既不至于立刻走，也很难自然地加入。吃完饭回家，别人问聚会怎么样，你可能只会说：“他们人都挺好的。”

+

+
+　　最简单的做法，是介绍时多说半句。
+

+
+　　这半句最好是真实的。随口编一个标签，像在给朋友做简历，也挺尴尬。你知道他最近在忙什么、喜欢什么、愿意聊什么，就从那里开始；还拿不准，提前问一句也行：“到时候我怎么介绍你比较舒服？”

+

+

+

+

+# 牛津的书虫
+
+*许地山*
+
+　　牛津实在是学者的学国，我在此地两年底生活尽用于波德林图书馆，印度学院，阿克关屋（社会人类学讲室），及曼斯斐尔学院中，竟不觉归期已近。
+
+　　同学们每叫我做“书虫”，定蜀尝鄙夷他说我于每谈论中，不上三句话，便要引经据典，“真正死路”！刘锴说：“你成日读书，睇读死你呀！”书虫诚然是无用的东西，但读书读到死，是我所乐为。假使我底财力、事业能够容允我，我诚愿在牛津做一辈子底书虫。
+
+　　我在幼时已决心为书虫生活。自破笔受业直到如今，二十五年间未尝变志。但是要做书虫，在现在的世界本不容易。须要具足五千条件才可以。五件者：第一要身体康健；第二要家道丰裕；第三要事业清闲；第四要志趣淡薄；第五要宿慧超越。我于此五件，一无所有！故我以十年之功只当他人一夕之业。于诸学问、途径还未看得清楚，何敢希望登堂入室？但我并不因我底资质与境遇而灰心，我还是抱着读得一日便得一日之益底心志。
+
+　　为学有三条路向：一是深思，二是多闻，三是能干。第一途是做成思想家底路向；第二是学者；第三是事业家。这三种人同是为学，而其对于同一对象底理解则不一致。譬如有人在居庸关下偶然捡起一块石头，一个思想家要想他怎样会在那里，怎样被人捡起来，和他底存在底意义。若是一个地质学者，他对于那石头便从地质方面源源本本他说。若是一个历史学者，他便要探求那石与过去史实有无底关系。若是一个事业家，他只想着要怎样利用石而已。三途之中，以多闻为本。我邦先贤教人以“博闻强记”，及教人“不学而好思，虽知不广”底话，真可谓能得力学底正谊。但在现在的世界，能专一途底很少。因为生活上等等的压迫，及种种知识上的需要，使人难为纯粹的思想家或事业家。假使苏格拉底生于今日的希拉，他难免也要写几篇关于近东问题底论文投到报馆里去卖几个钱。他也得懂得一点汽车、无线电的使用方法。也许他会把钱财存在银行里。这并不是因为“人心不古”，乃是因为人事不古。近代人需要等等知识为生活底资助，大势所趋，必不能在短期间产生纯粹的或深邃的专家。故为学要先多能，然后专政，庶几可以自存，可以有所供献。吾人生于今日，对于学问。专既难能，博又不易，所以应于上列三途中至少要兼二程。
+
+　　兼多闻与深思者为文学家。兼多闻与能干底为科学家。就是说一个人具有学者与思想家底才能，便是文学家；具有学者与专业家的功能底，便是科学家。文学家与科学家同要具学者底资格所不同者，一是偏于理解，一是偏于作用，一是修文，一是格物（自然我所用科学家与文学家底名字是广义的）。进一步说，舍多闻既不能有深思，亦不能生能干，所以多闻是为学根本。多闻多见为学者应有底事情，如人能够做到，才算得过着书虫的生活。当彷惶于学问底歧途时，若不能早自决断该向哪一条路走去，他底学业必致如荒漠的砂粒，既不能长育生灵，又不堪制作器用。即使他能下笔千言，必无一字可取。纵使他能临事多谋，必无一策能成。我邦学者，每不擅于过书虫生活，在歧途上既不能慎自抉择，复不虚心求教；过得去时，便充名士；过不去时，就变劣绅，所以我觉得留学而学普通知识，是一个民族最羞耻的事情。
+
+　　我每觉得我们中间真正的书虫太少了。这是因为我们当学生底多半穷乏，急于谋生，不能具足上说五种求学条件所致。从前生活简单，旧式书院未变学堂底时代，还可以希望从领膏火费底生员中造成一二。至于今日底官费生或公费生，多半是虚掷时间和金钱底。这样的光景在留学界中更为显然。
+
+　　牛津底书虫很多，各人都能利用他底机会去钻研，对于有学无财底人，各学院尽予津贴，未卒业者为“津贴生”，已卒业者为“特待校友”，特待校友中有一辈以读书为职业底。要有这样的待遇，然后可产出高等学者。在今日的中国要靠著作度日是绝对不可能的。因社会程度过低，还养不起著作家。┄┄所以著作家底生活与地位在他国是了不得，在我国是不得了！著作家还养不起，何况能养在大学里以读书为生的书虫？这也许就是中国底“知识阶级”不打而自倒底原因。

+# 自动续费最贵的地方，是替你跳过了重新选择
+
+<!-- daily-essay-id: 2026-11-22 -->
+
+<!-- wechat-digest: 自动续费省下的是一次操作，也容易把早已变化的使用习惯一起延续。定期看一眼服务是否仍在参与生活，花钱才更接近自己的选择。 -->
+
+　　自动续费最贵的地方，是替你跳过了重新选择。
+
+　　很多服务开通时都很有道理。
+
+　　那段时间常听音乐，于是办了会员；换手机时担心照片丢，于是买了云空间；准备学一门课，先订一个月试试看。页面上“到期自动续费”的选项已经勾好，价格也不算高，顺手就过去了。
+
+　　后来生活变了。
+
+　　耳机很久没戴，照片早就转存到别处，课程打开两节之后停在了那里。每个月扣款的提醒偶尔跳出来，金额小到不足以引起警觉，于是手指一划，又过去了。
+
+　　等某天整理账单，才发现好几项服务还在续，连自己都要想一会儿：当初是为了什么开的？
+
+　　很多人把这件事归为粗心。其实自动续费本来就是为“少操心”设计的。它替你省掉了每个月确认、付款、重新开通的几步，也顺手把一次原本会发生的提问省掉了：我现在还想要它吗？
+
+　　**省事和失去检查，往往是同一个动作的两面。**
+
+　　对每天都会用的服务来说，这份省事很有价值。常用的存储空间、每周固定要看的内容、离不开的软件，到了续费那天还要从头比一遍，确实也挺烦。生活里有很多重复事项，交给默认设置处理，脑子可以留给别的地方。
+
+　　问题出在使用已经变了，扣款却没有变。
+
+　　服务商最清楚这一点。开通按钮通常很大，取消入口往往藏在账户、订阅、管理计划的好几层里面。它并没有做错什么，规则也写在那里；只是这套设计天然会利用一个事实：人总有更紧急的事情要做，几十块钱的提醒很难赢过眼前的工作和消息。
+
+　　所以，自动续费卖给你的不只是内容或容量，还包括一小段“我下个月再想”的延后。
+
+## 让每一笔续费重新回答一个问题
+
+　　取消自动续费，不代表从此和这些服务绝交。
+
+　　有人一看到这个建议，就觉得要开始过一种抠抠搜搜、每笔钱都算到小数点后两位的日子。倒也不至于。钱花出去，换来便利、娱乐和轻松，本来就是很正常的事。
+
+　　真正值得保留的是判断：它最近给我的生活带来了什么？
+
+　　比如一个视频会员。过去一个月里，你看了几部想看的片子，家里人也常用，那它继续扣费很合理。若只是偶尔刷到“会员专享”的标记，随后又去做别的事，可能等真的想看时再开会更合适。
+
+　　区别不在于金额绝对值，而在于这笔钱有没有在参与当下的生活。
+
+　　有些服务甚至会让人产生一种奇怪的负担。课程订了却没学，健身卡办了却没去，软件会员买了却一直闲置。每次看见扣费记录，心里先冒出来的不是“它帮到了我”，而是“我又没做到”。
+
+　　这时续费已经不只是消费，还带着一点对旧计划的拖欠。
+
+　　有人会为了证明当初买得没错，硬逼自己去用。周末本来想休息，忽然想起会员快到期，又打开课程看二十分钟。看完也没有收获，只是在给那笔钱补一张心理发票。
+
+　　这就有点本末倒置了。
+
+　　买课程时，你想得到的也许是一个学习机会；后来发现它不适合当前节奏，停掉订阅，并不等于过去的钱全白花。至少你知道了，这种安排暂时接不住自己。把它留着，往往只会让那个未完成的计划每个月回来敲一次门。
+
+　　**付费可以是为了使用，也可以是为了试错。试过以后调整，本来就是消费的一部分。**
+
+　　具体怎么做很简单。可以找一个相对固定的时间，比如每个月发工资后的某天，或者换季整理东西时，打开订阅列表看一眼。每一项只问三个问题：我上次用它是什么时候？接下来一个月有没有明确的用途？它替我省下了什么麻烦，或者带来了什么快乐？
+
+　　答得出来，就留着。答不出来，先关掉自动续费也没关系。真正需要时，大多数服务都能重新开通；那时再付钱，至少是为了眼前清楚的需求。
+
+　　当然，也有些订阅的意义很难用次数衡量。一个很少打开的存储服务，可能装着重要备份；一份长期支持的内容订阅，可能是你愿意给创作者的一点稳定收入。只要自己知道为什么留，它就是一笔有来处的支出。
+
