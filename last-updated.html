+# 一个人应该活得是自己并且干净
+
+*顾城*
+
+　　人的生命里有一种能量，它使你不安宁。说它是欲望也行，幻想也行，妄想也行，总之它不可能停下来，它需要一个表达形式。这个形式可能是革命，也可能是爱情；可能是搬一块石头，也可能是写一首诗。只要这个形式和生命力里的这个能量吻合了，就有了一个完美的过程。
+
+　　一个彻底诚实的人是从不面对选择的，那条路永远会清楚无二地呈现在你面前，这和你的憧憬无关，就像你是一棵苹果树，你憧憬结橘子，但是你还是诚实地结出苹果一样。
+
+　　西方爱情是强烈开放的花朵，东方爱情是两朵花之间微妙的芳香。
+
+　　自由并不是你不知道干什么好，也不是你干什么都可以不坐牢；自由是你清楚无疑你要干什么，不装蒜，不矫揉造作，无论什么功利结果，会不会坐牢或者送死，都不在话下了。对于惶惑不知道干什么的人来说，自由是不存在的；对于瞻前顾后、患得患失的人来说，自由是不可及的。
+
+　　一个人，生活可以变得好，也可以变得坏；可以活得久，也可以活得不久；可以做一个艺术家，也可以锯木头，没有多大区别。但是有一点，就是他不能面目全非，他不能变成一个鬼，他不能说鬼话、说谎言，他不能在醒来的时候看见自己觉得不堪入目。一个人应该活得是自己并且干净。
+
+　　命运不是风来回吹，命运是大地，走到哪里你都在命中。
+
+　　贾宝玉是真性情，鲁智深也是真性情；鲁智深一句唱词儿“赤条条来去无牵挂”，贾宝玉眼泪就下来了，顿时就有了感觉。可是你让贾宝玉抡个棍子去打，那无疑是找死。他们爱好不同，性情很不一样，但是呢，都是真性情，它就通了。
+
+　　从叶到花，或从花到叶，于科研是一个过程，而于生命自身则永远只在此刻。花和叶都是一种记忆方式。果子同时也是叶子。生命是闪耀的此刻，不是过程，就像芳香不需要道路一样。
+
+　　中国人只创造了两个理想，一个是山中的桃花源，一个是墙里的大观园。我的笑话不过是把大观园搬到了山里，忘了林黛玉的药锄是葬花用的。
+
+　　我到了新西兰一个小岛上，把身体交给了劳动。四年之后，有一天，我忽然看见黑色的鸟停在月亮里，树上的花早就开了，红花已经落了满地。这时候我才感到我从文化中间、文字中间走了出来。万物清清楚楚地呈现在你的心里，一阵风吹过，鸟就开始叫了，树就开始响了。这个时候我明白了一个道理：只有在你生命美丽的时候，世界才是美丽的。

+# 坏消息说得早一点，别人就多一点选择
+
+<!-- daily-essay-id: 2026-10-17 -->
+
+<!-- wechat-digest: 已经可能影响约定的变故，值得在彻底确定之前说明；把已知情况、剩余疑问和下次确认时间讲清楚，能让对方及时调整安排，也不必把每一点不安都变成警报。 -->
+
+　　有一种不靠谱，是一直想等事情解决了，再告诉别人刚才出了问题。
+
+　　听起来甚至挺负责：我先自己想办法，能处理就不让别人操心。可一旦没处理好，对方收到的就会是两个坏消息。事情办不成了，而且现在才知道。
+
+　　后一个，有时比前一个更麻烦。
+
+　　比如几个人约好周末去郊外，你答应开车。周四车出了故障，送去维修，能不能在周六之前修好，还没确定。你想着再等等，万一明天就好了呢，没必要现在把大家弄得紧张。
+
+　　周五问了一次，还得等。你又想，实在不行就借辆车，也不是完全没有办法。
+
+　　到了周六早上，车没修好，也没借到。你在群里说，很抱歉，今天可能去不了了。
+
+　　朋友不高兴，你也委屈：这两天一直在想办法，没闲着啊。
+
+　　但他们看不见你试过多少办法。他们能看见的是，自己已经收拾好东西、腾出了周末，甚至站在楼下等了。你在争取修好车的同时，也替他们决定了这两天不用考虑别的安排。
+
+　　这个决定，你未必有资格替他们做。
+
+　　**事情还没确定会失败，不妨碍你先告诉别人，它已经不再稳妥。**
+
+　　周四就说“车送修了，周六能不能用还没确定，我明天下午再问一次”，并不等于宣布行程取消。有人可能知道另一种去法，有人愿意一起等，也有人会说，那这次先别折腾了。
+
+　　这些选择，至少还能讨论。到了约定出发的时间再说，讨论的余地就小多了。
+
+　　我觉得，很多人不愿意提前讲，恰恰是怕显得自己不可靠。答应的时候说得那么满，才过两天又说有变，像是给自己的承诺打折。
+
+　　于是就想把中间那段不确定藏起来，争取最后交出一个正常结果。真能办成，大家什么都不知道，自己也保住了体面。
+
+　　问题在于，办不成的那一边，也得算进去。你拿来争取体面的这段时间，可能正是别人用来改变安排的时间。
+
+　　如果你只是在做自己的事，晚一点下判断，当然可以。但已经有人根据你的承诺行动，就不能只按自己的感受决定什么时候开口了。
+
+　　工作里也是。说好了周三给同事一份材料，周二发现缺了一项关键内容，还在等别人回复。你可以继续催，也可以想替代办法，但最好别让同事一直以为周三收到的一定是完整版本。
+
+　　他可能愿意先拿已有的部分，也可能需要调整自己的顺序。你不说，他就只能照旧等着，到时候跟你一起着急。
+
+　　把麻烦留到最后才交出去，不能因为前面努力过，就算替别人省了心。
+
+　　当然，提前说明也不等于不停地播报自己的焦虑。
+
+　　“我感觉可能不太行”“又有点担心”“也许会出问题”，一天下来发十条，对方还是不知道该不该改计划。这只是让两个人一起悬着。
+
+　　有用的是把具体情况讲出来：哪件已经发生的事影响了约定，目前还有什么没确认，你准备什么时候再给一次明确答复。
+
+　　至于自己脑子里闪过的每一种糟糕可能，不必都拿出来让别人陪着想。
+
+　　而且，下次确认时间不能只看自己什么时候方便。朋友如果周五中午之前就得决定是否换一种出行方式，你说周五深夜再告诉他，虽然也叫提前通知，实际没给他留下多少余地。
+
+　　可以直接问一句：“你最晚什么时候需要定下来？”知道这个时间，再判断还要等多久。
+
+　　对方也有自己要安排的事情。把这个时间问清楚，比单方面保证“我肯定尽快”有用。
+
+　　另一边，接到这种提醒的人，也可以让提前开口变得容易一点。对方说可能赶不上，先确认影响和替代办法，别立刻把一句说明理解成“他已经不打算做了”。
+
+　　如果每次早说都挨骂，最后一刻才说反而没人有空追究，那下次别人继续憋着，也没什么奇怪的。当然，这不能替隐瞒开脱，只是处理问题时，也该看看自己鼓励了怎样的做法。
+
+　　至于那种每次都承诺、每次都预警、最后照样做不到的人，不能拿“我已经提前说了”当作交代。通知只是让别人有机会调整，原来的失约有没有补救、以后还该不该答应，仍然要处理。
+
+　　提前讲并不会自动消除坏消息，也不保证对方一定满意。它能做的很具体：让别人知道自己正在等什么，还有没有必要继续等。
+
+　　下次约定的事情出现变故，不必等到手里只剩一句“没办法了”，才想起来联系对方。还在想办法的时候，就可以把情况说一声。
+
+　　你可以继续努力，对方也可以另作准备。这两件事本来可以同时发生。
+

+# 反复出现的例外，应该拿来修改规则
+
+<!-- daily-essay-id: 2026-10-16 -->
+
+<!-- wechat-digest: 一条规则如果总要靠私下通融才能执行，就该检查它是否还适合实际条件；把反复发生的例外摆出来讨论，才能让不擅长求情的人也得到明确而公平的安排。 -->
+
+　　一条规则总要靠破例才能执行，我会先怀疑规则，而不是先夸大家懂得变通。
+
+　　偶尔通融，当然是好事。但如果同样的麻烦每周都来一遍，每次都得找同一个人说情，那这份“灵活”，多少有点值得重新看看。
+
+　　设想一个团队，规定周五下午五点之前交齐周报，其中一项必须填写合作方确认后的数据。可合作方通常六点才发来最终结果。
+
+　　第一周，有人提前解释情况，负责人说，那你晚一点交吧。第二周，还是这样。第三周，大家学会了：五点前先发一句“今天又得晚点”，等一句“好的”。
+
+　　看起来相处得很融洽，负责人也挺体谅人。
+
+　　可是，这几句对话到底解决了什么？数据没有提前，报告没有早交，大家只是在重复申请同一个许可。
+
+　　更有意思的是，新来的人不知道有这个惯例，可能先填一个未确认的数，赶在五点之前交上去。后来发现不对，再补发一遍。认真按规定办事的人，反而多做了两次。
+
+　　这时候还夸一句“你得学会灵活处理”，就很没道理了。一个人凭什么要靠猜，才能知道纸面上的要求究竟哪一条算数？
+
+　　**反复发生的例外，至少应该成为重看规则的理由。**
+
+　　注意，是重看，不是立刻取消。
+
+　　先问清楚五点这个时间是干什么用的。如果后面的人六点要根据报告做决定，那截止时间确实有用。问题可能在数据来源，也可能在报告要求把尚未确定的信息当作确定信息来交。
+
+　　这时可以约定，五点先交已有内容，缺的数据标明待确认，收到后再补。后面的人知道哪些能用，哪些还不能用，就不必把一份看似齐全的报告当成全部定案。
+
+　　如果报告周一才有人看，五点只是几年前随手定下来的时间，那把截止时间改一改，又有什么不得了的？
+
+　　规则总得服务于某件事。那件事已经换了样子，规则却原封不动，最后就只能靠每个人额外费心去迁就它。
+
+　　我不太喜欢把这种费心一概叫作成熟。新人要记住哪些话不能照字面理解，老员工要记住找谁开口，负责人还得反复批准。做事之前，先学一套没有写出来的做事办法。
+
+　　更麻烦的是，谁能得到例外，渐渐也可能变成一门关系学问。
+
+　　熟悉的人直接说“还是老样子”，不熟悉的人写一大段解释。敢开口的每次都过，怕添麻烦的每次都硬扛。最后看起来人人遵守同一条规则，实际承担的东西却不一样。
+
+　　当然，不能因此要求所有情况都必须一样处理。临时遇到困难，得到一点照顾，没什么问题。一个人的特殊需要，也不必等到多数人都有才值得回应。
+
+　　但能否把通融的依据讲清楚，是另一回事。比如外部信息尚未到齐时，可以怎么交、什么时候补；遇到突发情况时，联系谁，由谁接着处理。能提前说明的部分，没必要每次都重新求人。
+
+　　这既让申请的人省事，也能让负责批准的人少背一点压力。以前批了这个没批那个，别人只能猜是不是偏心；条件说清楚之后，至少可以围绕具体差别来讨论。
+
+　　不过，有些例外反复出现，恰恰暴露的不是规则太死，而是有人总把自己的方便排在别人前面。
+
+　　比如说好会议只开半小时，有个人每次都临时加话题，讲到所有人后面的安排都被耽误。总不能因为他屡次超时，就直接把会议改成两个小时吧。
+
+　　这里该问的，是为什么他的临时起意，总能换来其他人的集体加班。反复出现只说明值得查原因，不自动说明应该顺着它改。
+
+　　所以我觉得，比“大家灵活一点”更有用的，是把最近几次例外放到一起看。卡住的是哪一步？原来的条件还在不在？谁为这次通融多做了事情？以后碰到同样情况，能不能事先知道怎么办？
+
+　　这些问题说清楚，可能改掉一个时间，也可能保留原来的限制，或者补上一种大家都能使用的处理办法。都比把同一件事永远留在私下商量里强。
+
+　　如果你有权定规则，下次收到熟悉的破例申请时，可以少做一次即时判断，抽空问问它为什么又来了。如果你没有这个权力，也可以把几次相同的卡点摆出来，提出一个具体的修改建议。
+
+　　“这次能不能通融一下”，可以解决今天的事。“下次遇到同样情况，大家按什么办”，才有机会让明天不用再求一次。
+
+<br />
+
+　　南国微雪 Miyuki

+# 以补水为噱头的所有护肤品，都是骗子
+
+<!-- daily-essay-id: 2026-10-15-extra-skincare -->
+
+<!-- wechat-digest: 保湿有真实作用，值得警惕的是把角质层水合包装成深层灌水，再用缺水解释所有皮肤问题；判断产品应看完整配方和实际证据，而不是补水故事有多动听。 -->
+
+　　标题里最重要的两个字，是“噱头”。
+
+　　护肤品可以改善干燥，保湿也确实有用。如果把所有标着“补水”的产品一律说成无效，那同样是在胡说。今天要拆的是另一种东西：把脸讲成一块干海绵，再告诉你，只要买它的水，一层层灌进去，皮肤的问题就都能解决。
+
+　　干燥？缺水。出油？还是缺水。长痘、泛红、细纹，也都给你归到缺水。最后不管你有什么问题，答案都是同一瓶东西。
+
+　　这种解释是不是方便得过头了？
+
+　　先说一点最基本的。皮肤最外面的角质层需要维持合适的水分，但维持水分，涉及吸引、保持水分，以及减少蒸发。甘油这类吸湿成分、凡士林这类封闭成分，做的事情就不完全一样。[DermNet 对保湿成分的说明](https://dermnetnz.org/topics/emollients-and-moisturisers)把这些作用分得很清楚。
+
+　　所以，一瓶东西抹起来很水，不足以说明它保湿好；一款东西主要帮助减少水分流失，也完全可能是有用的保湿产品。
+
+　　**把皮肤弄湿，和帮助皮肤维持合适的含水状态，不是一回事。**
+
+　　这也不意味着皮肤是完全不透水的塑料袋，或者外用产品绝不可能增加角质层含水量。为了反对广告，编一个方向相反的神话，最后只是换个人误导消费者。
+
+　　美国皮肤科学会对保湿产品的解释，就包括增加皮肤水分、减少水分流失这两方面。它也建议在清洁后皮肤仍湿润时使用合适的保湿产品，帮助留住水分。[资料：如何选择保湿产品](https://www.aad.org/public/everyday-care/skin-care-basics/dry/pick-moisturizer)。
+
+　　真正值得追问的是：广告嘴里的“补”，到底补到了哪里，维持多久，改善了什么？
+
+　　如果拿出来的证据，只是使用后短时间内角质层含水量提高，那它支持的就是这个结果。不能下一句话就变成“直达肌底”，再下一句话变成“从根源逆转衰老”。
+
+　　“肌底”到底指哪里？用什么办法测的？测过成品，还是只讲某个原料的故事？这些问题不回答，画面里的水珠倒是一颗比一颗会钻，穿过几层动画，皮肤就年轻了。
+
+　　动画做得好，证明的是动画做得好。
+
+　　面膜也是一样。敷完觉得柔软、水润，不必否认自己的感受。有些面膜确实能帮助保湿，但这不能自动证明它修复了所有屏障问题，更不能代替痤疮、湿疹等疾病的治疗。美国皮肤科学会也明确区分了面膜的护理作用和疾病治疗。[资料：面膜的作用与局限](https://www.aad.org/public/everyday-care/skin-care-secrets/routine/facial-masks-and-skin-care)。
+
+　　你买的是一段舒服的护理体验，可以。愿意为肤感、气味或者包装付钱，也可以。可卖体验，就别硬说成治疗；改善了水润感，就别顺手把抗衰和治痘的功劳也认走。
+
+　　尤其是“出油就是缺水，所以越油越要买补水套装”，这种推销方式，我很不喜欢。
+
+　　痘肌可能需要保湿，某些祛痘治疗还会使皮肤干燥，合适的保湿产品能提供帮助。但保湿属于配合护理，不能由此推导出，痘痘都是水没补够。美国皮肤科学会的痘肌保湿建议，也没有把保湿当成可以替代全部治疗的万能答案。[资料：痘肌为什么可能需要保湿](https://www.aad.org/public/diseases/acne/skin-care/moisturizer)。
+
+　　把不同问题全装进一个“缺水”的口袋，消费者就不用再判断原因了。只要不断购买、不断叠加，没改善还可以继续解释成补得不够。
+
+　　这才是我反感的地方：产品到底有没有做到承诺的事情，反而变得无法检验。
+
+　　买的时候，不妨把那些漂亮词换成几个普通问题。这瓶东西主要解决什么？有没有针对完整产品的证据？效果在什么条件下测得，能维持多久？它承诺的，和拿出来证明的，是不是同一件事？
+
+　　也别走到另一个极端，只看成分表里有没有某个明星名字，就宣布产品一定好用。列出了甘油或者透明质酸，不等于你已经知道整套配方的表现，更不等于每个人都适合。
+
+　　如果用后持续刺痛、泛红，别把它解释成“太缺水，正在吸收”。先停下可疑产品，必要时找皮肤科医生判断，别让一句销售话术替你解释身体的反应。[资料：护肤品出现不良反应时怎么办](https://www.aad.org/public/everyday-care/skin-care-secrets/prevent-skin-problems/test-skin-care-products)。
+
+　　保湿是一项具体的功能。有作用，也有边界；能测量，就应该经得起追问。
+
+　　只要把这些话讲明白，“补水”两个字没有什么原罪。可如果一件产品非得靠虚构的深层灌水、包治百病的缺水理论才能卖出去，那我还是标题那个态度：这种生意，做的就是骗。

+# 不喜欢一部作品，不必先证明它很差
+
+<!-- daily-essay-id: 2026-10-15 -->
+
+<!-- wechat-digest: 个人感受不需要靠贬低作品来获得许可，评价作品则值得把依据说具体；分清这两件事，既能保留自己的口味，也能给理解不同的欣赏方式留一点余地。 -->
+
+　　一部作品有它的好，你也可以不喜欢。这两件事放在一起，没什么矛盾。
+
+　　麻烦的是，有时候连不喜欢都需要先找一个足够体面的理由。仿佛只要没能指出作品哪里差，就只能承认自己的欣赏水平不够。
+
+　　比如朋友推荐一部电影，说里面几段安静的镜头特别动人。你看了一半，只觉得慢，人物走来走去，迟迟没有发生自己想看的事情。
+
+　　朋友问怎么样。你说没看进去，他开始解释这些镜头里的光线、人物的处境，以及前后呼应的细节。
+
+　　你听懂了，也承认有些地方处理得细，但仍然不想接着看。
+
+　　到这里，本来就可以结束。偏偏聊天很容易继续往前拱：既然都听明白了，为什么还是不喜欢？是不是没认真看？你被问得烦了，干脆说这电影就是故弄玄虚，喜欢的人也不过是在装。
+
+　　一个人原本只是想关掉电影，最后却得把电影和喜欢它的人一起否定，才能走得理直气壮。
+
+　　这个弯绕得实在有点远。
+
+　　**承认一部作品有长处，并不等于答应把自己的时间交给它。**
+
+　　你知道某个镜头花了心思，知道一段文字写得精巧，也可能对它讲的事情毫无兴趣。做得用心、做得熟练，和你愿不愿意看下去，之间还隔着你此刻想得到什么。
+
+　　想轻松看个故事的时候，未必愿意跟着人物反复沉默。喜欢热闹的场面，也不需要先证明安静的场面没有价值。各自选想看的，原本没有那么难。
+
+　　我觉得，“我不喜欢”这句话很有用的一点，是它让人有机会把感受说准，而不必马上宣布一个对所有人都成立的结论。
+
+　　“中间那段我一直在等事情往前走，等得有点烦”，比“这导演根本不会拍电影”，更能说明你遇到了什么。别人听完，也更容易判断自己会不会有相似的感受。
+
+　　说得具体，并不见得就温和。某个转折让你觉得前面的铺垫全白费了，某段对白听起来很生硬，完全可以直接讲。喜欢它的人也可以指出，你漏掉了哪一处内容。
+
+　　这时候讨论才有东西可谈。双方可以回去核对，而不必争谁的品位比较高级。
+
+　　当然，也别把所有批评都塞进“口味不同”里。
+
+　　假设一部小说前面明确写过某个角色不知道一件事，后面却让他凭这件事做出关键决定，中间没有交代他如何得知。读者问这里是不是漏了什么，这就是一个可以检查的具体问题。
+
+　　有人觉得不影响阅读，有人因此看不下去，重视程度可以不同。但拿一句“你不懂欣赏”挡回去，并没有解释这个问题。
+
+　　反过来，读者也可能漏看了一段。别人把那一段找出来，承认自己记错就好，不需要再临时添一条罪名，保证这部作品始终站在自己不喜欢的位置上。
+
+　　纠正一处批评，不会强迫你改成喜欢。
+
+　　这点很省事。你不用为了保住自己的感受，连明明存在的优点都拒绝看见；也不用因为一个缺点被解释清楚，就勉强给出完全相反的评价。
+
+　　还有一种情况值得留一点余地：不喜欢的东西，未必永远都不会喜欢。
+
+　　某种叙事方式不熟悉，刚开始看觉得吃力，了解一点之后也许会有新的乐趣。愿意尝试，当然可以多看一点，听听别人具体喜欢哪里。
+
+　　但这个尝试最好来自好奇。为了避免被说没水平，硬把每次娱乐都变成补课，时间花了不少，最后只记住了自己受了多少罪，那也没什么必要。
+
+　　不必立刻接受，也不用提前把门焊死。今天不想看，关掉；哪天忽然感兴趣，再找回来。口味变了，说明你此刻有了别的感受，犯不着跟过去的自己打一架。
+
+　　如果轮到自己推荐作品，也可以留意一下，对方是在问你为什么喜欢，还是已经告诉你他不喜欢了。前者可以聊，后者未必需要再来一轮劝说。
+
+　　把自己觉得动人的地方分享出去，已经很好。朋友没有得到同样的感动，不代表你的分享失败，更不代表你要负责把他教到喜欢为止。
+
+　　那部电影可以继续是朋友心里的好电影，也可以停在你播放到一半的位置。你知道它哪里用心，也知道自己今晚更想看别的。
+
+　　换一部就是了，不必先把上一部判得一无是处。
+
+<br />
+

+# 卖笑人
+
+*伯尔*
+

+# 已经决定的事，就别假装还在商量
+
+<!-- daily-essay-id: 2026-10-14 -->
+
+<!-- wechat-digest: 商量需要让对方的意见有机会改变安排，提前讲清哪些已定、哪些可改、由谁决定，才能避免用一句客气的询问，把未经同意的后果交给别人。 -->
+
+　　如果只准备接受“可以”这个答案，那就先别说自己是在征求意见。
+
+　　比如两个人合租，客厅原本留了一块空地。你觉得放张大桌子更方便，挑好了款式，下了单，约好了送货，才发消息问室友：“我买了张桌子放客厅，你觉得怎么样？”
+
+　　室友说，那里平时要晾衣服，不太想再添家具。
+
+　　你一听就急了：尺寸都量好了，钱也付了，退起来很麻烦。况且桌子两个人都能用，怎么这点事情还要反对？
+
+　　那刚才问他，是准备让他决定什么呢？
+
+　　选桌子的时候没有他，付款的时候没有他，等到拒绝已经会制造麻烦了，才轮到他发表意见。他想保留原来的空地，还得先跨过你已经付出的时间和金钱。
+
+　　看起来给了选择，拒绝的代价却提前安排好了。
+
+　　我觉得，这种商量最让人不舒服的地方，是对方既要接受一个没有参与过的决定，又要配合表示自己愿意。答应了，事情就变成“咱们商量好的”；不答应，又像在故意让已经忙了一圈的人难堪。
+
+　　他原本只是不想要那张桌子，怎么突然多出这么多事情要解释？
+
+　　**商量要发生在意见还能改变安排的时候。**
+
+　　放在这件事里，就是先问客厅有没有必要添桌子。如果愿意添，再一起看放哪里、多大合适、谁来买。每一步未必都要聊很久，但关键的分歧要在事情做定之前出现。
+
+　　有人可能会说，什么都提前问，太麻烦了。对方只会说随便，真让他挑，又挑不出来，最后还不是自己做。
+
+　　这个麻烦确实有。但可以带着具体方案去问，不必把一张白纸推给别人，让他替你从头想。
+
+　　“我想在这里放张桌子，但会占掉现在晾衣服的位置，你愿不愿意？不方便就先不买。”照片、尺寸和影响都摆出来，对方更容易判断，也知道现在说不还来得及。
+
+　　比起问一句“怎么样”，这种问法要明确一点。它承认自己的想法会改变别人使用空间的方式，也承认对方可能不喜欢。
+
+　　当然，真正商量，不要求每条意见都被采用，更不要求所有事情都让别人做主。
+
+　　自己房间里换一把椅子，没有占用共用空间，也不用别人出钱，决定可以自己做。想给室友看看，就说“我选了这把，给你看看”。他不喜欢这个颜色，也不妨碍你喜欢。
+
+　　已经委托你挑的东西，同样可以在约好的范围里自己决定。预算、尺寸、谁来拍板，提前说清楚，没必要买支笔也反复开会。
+
+　　问题出在，你究竟拥有多大的决定权，以及有没有把这个范围告诉别人。不能在需要对方配合时说大家一起商量，在听到不同意见时又改口说自己已经决定。
+
+　　有些事情也确实只有一部分能改。比如借到的活动场地只有周日下午能用，时间定不了别的，但活动内容还可以调整，那就直接讲清楚：时间受限制，这次主要商量内容，不能来的也提前说。
+
+　　有限的选择没有什么见不得人的。让人以为所有地方都能提意见，花时间想完，你再逐条宣布这些都没办法改，才是在白白消耗别人的认真。
+
+　　而且，别人反对时，未必已经准备好另一个完整方案。室友只知道客厅不能再堵，也足够提出这个问题。不能要求他先找到新的晾衣位置，才有资格不同意买桌子。
+
+　　提出改变的人，也得负责说明改变之后，原来那些事情怎么办。
+
+　　轮到被征求意见的一方，如果分不清对方到底想问什么，可以先确认一句：“现在还没定，我可以提出调整，是吗？”或者问得再具体一点：“如果我觉得不合适，这张桌子还可以先不买吗？”
+
+　　这比猜对方的语气省事。范围说清楚，后面才知道自己是在帮忙挑东西，还是在决定一块共同空间怎么用。
+
+　　如果已经先买了，也还有可以做的事。承认自己问晚了，查清楚能否取消、换尺寸或者放到自己的房间，再把可行的办法拿出来谈。
+
+　　自己先下单造成的麻烦，就别变成催别人点头的理由。对方愿意迁就，是另外一份体谅，不能靠一句“都买了”替他答应。
+
+　　下次准备说“跟你商量个事”之前，先想清楚：对方如果回答不愿意，自己打算怎么办？
+
+　　有空间改，就认真问。确实由自己决定，也可以把决定和影响说明白。至于本来就需要双方同意的事情，最好让订单再等一会儿。
