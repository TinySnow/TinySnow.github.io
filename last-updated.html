+# 谈海明威
+
+*加西亚·马尔克斯*
+
+　　我一眼就把他认出来了，那是 1957 年巴黎一个春雨的日子，他和妻子玛丽·威尔许经过圣米榭勒大道。他在对街往卢森堡公园的方向走，穿着破旧的牛仔裤、格子衬衫，戴一顶棒球帽。惟一看起来跟他不搭调的是一副小圆金属框眼镜，仿佛很年轻就当上祖父似的。他已经 59 岁了，体格壮硕，想不看见都不行，他无疑想表现出粗犷的味道，可惜没有给人这种感觉，他的臀部很窄，粗糙的伐木靴上方是一双略显瘦削的腿。在旧书摊和索邦大学出来的大批学子当中，他显得生气蓬勃，想不到四年后他就去世了。
+
+　　好像总是这样，在一刹那间，我发现自己被分成了两个角色，而且在相互竞争。我不知道该上前去请他接受访问，还是过街去向他表达我对他无限的景仰。但不管怎么做对我来说都很不容易。当时我和现在一样，说得一口幼稚园英语，也不清楚他的斗牛士西班牙语说得怎么样。为了不要破坏这一刻，我两样都没做，只像人猿泰山那样用双手圈在嘴巴外面，向对街的人行道大喊：“大——大——大师！”海明威明白在众多学生中不会有第二个大师，就转过头来，举起手用卡斯蒂亚语像小孩子似地对我大叫：“再见，朋友！”以后我再也没见过他。
+
+　　当时我 28 岁，是报社从业人员，在哥伦比亚出版过一本小说，得了一个文学奖，可是仍在巴黎漫无目的地飘荡着。我景仰的大师是两位极为不同的北美洲小说家。当年他们的作品只要出版过的我一律没放过，但我不是把他们当作互补性的读物，而是两种南辕北辙截然不同的文学创作形式。一位是威廉·福克纳，我一直无缘见到他，只能想像他是卡尔迪埃·布勒松拍的那张著名肖像中的模样，在两只白狗旁边，穿着衬衫在手臂上抓痒的农夫。另一位就是在对街和我说再见，立刻又消失在人群中的人，留给我一种感觉，曾经有什么已经出现在我的生命里，而且从来没有消失过。
+
+　　不知道是谁说过，小说家读其他人的小说，只是为了揣摩人家是怎么写的。我相信此言不假。我们不满意书页上暴露出来的秘诀：甚至把书翻过来检查它的接缝。不知道为什么，我们把书拆到不能再拆，直到我们了解作者个人的写作模式，再装回去。但这样分析福克纳的小说，就未免令人气馁，他似乎没有一个有机的写作模式，反而是在他的圣经世界里瞎闯，仿佛在一个摆满水晶的店里放开一群山羊。分解他的作品，感觉就像一堆剩下的弹簧和螺丝，根本不可能再组合成原来的样子。对比之下，海明威虽然比不上福克纳的发人深省、热情和疯狂，却严谨过人，零件就像货车的螺丝一样看得清清楚楚。也许就因为这样，福克纳启发了我的灵魂，海明威却是对我的写作技巧影响最大的人——不仅是他的著作，还有他对写作方法与技巧的惊人知识。《巴黎评论》登的那篇他和乔治·普林顿历史性的访谈中，他揭示了一套和浪漫时期创作理念相反的说法：经济的不虞匮乏和健康的身体对写作有帮助；最大难题就是把文字配置妥当；当你觉得下笔不如过去容易，应该重读自己的作品，好记起写作从来不是一件容易的事；只要没有访客和电话，哪里都可以写作；常有人说新闻会扼杀一个作家，其实正好相反，只要能赶快把新闻那一套丢开，倒可以成就一个作家。他说：“一旦写作上了瘾，成为最大的乐趣，不到死的那天是不会停笔的。”最后他的经验发现，除非知道第二天要从哪里接下去，否则不能中断每天的工作。我认为这是对写作最有用的忠告。作家最可怕的梦魇就是早上面对空白稿纸的痛苦，他这番话无异于一贴万灵丹。
+
+　　海明威的作品全都显现了他如昙花一现般灿烂的精神。这是可以理解的。他对技巧那种严格的掌控所建构出的内在张力，在长篇小说广泛而冒险的范围中无法维系下去。这是他出类拔萃的特质，也是他不该企图逾越的局限。就因为如此，海明威的余文赘语比其他作家的更显眼，他的小说就像是写过了头，比例不相称的短篇小说。对比之下，他的短篇小说最大的优点就是让你觉得少了什么，这也正是其神秘优美之所在。当代大作家博尔赫斯也有同样的局限，但他懂得不要贸然逾越。
+
+　　弗朗西斯·麦康伯一枪射死狮子，可以说给读者上了一堂打猎课，但也正是写作方法的总结。海明威在一篇短篇小说中描写一头来自里瑞亚的公牛，从头牛士胸前擦过，又像“转角的猫”似地快速跑回来。容我斗胆一言，我相信这样的观察，就是那种最伟大的作家才会冒出来的傻气小灵感。海明威的作品充满了这种简单而令人目眩的发现，显示此时他已经调整了他对文学写作的定义：文学创作犹如冰山，有八分之七的体积在下面支撑，才会扎实。
+
+　　对技巧的自觉无疑是海明威无法以长篇小说著称，而以较工整的短篇小说扬名立万的理由。谈到《丧钟为谁而鸣》，他说并没预先计划好故事架构，而是每天边写边想。这用不着他说，看也看得出来。对比之下，他那些即兴创作的短篇小说却无懈可击。就像某个 5 月天因为暴风雪，使得圣伊西德罗庆典的斗牛表演被迫取消，那天下午他在马德里的自助式公寓写了三个短篇小说，据他自己跟乔治·普林顿说，这三篇分别是《杀人者》、《十个印第安人》和《今天是星期五》，全都非常严谨。照这样说来，我个人觉得他的功力最施展不开的作品是短篇小说《雨中的猫》。
+
+　　虽然这对他的命运似乎是一大嘲讽，我倒觉得他最迷人最人性的作品就是他最不成功的长篇小说：《过河入林》。就像他本人透露的，这原本是一篇短篇小说，不料误打误撞成了长篇小说，很难理解以他如此卓越的技巧，会出现这么多结构上的缺失和方法上的错误，极不自然，甚至矫揉造作的对话，竟然出自文学史上的巨匠之一。此书在 1950 年出版，遭到严厉批评，但这些书评是错误的。海明威深感伤痛，从哈瓦那发了一封措词激烈的电报来为自己辩护，像他这种地位的作家，这么做似乎有损颜面。这不只是他最好的作品，也是最具个人色彩的长篇小说。他在某一秋天的黎明写下此书，对过往那些一去不回的岁月带着强烈的怀念，也强烈地预感到自己没几年好活了。他过去的作品尽管美丽而温柔，却没有注入多少个人色彩，或清晰传达他作品和人生最根本的情怀：胜利之无用。书中主角的死亡表面上平静而自然，其实变相预示了海明威后来以自杀终结自己的一生。
+

+# 改习惯之前，先看看自己把事情摆得有多顺手
+
+<!-- daily-essay-id: 2026-10-05 -->
+
+想少做一件事，却把它安排得随手就能做，然后要求自己每次都忍住，这个计划从一开始就在为难自己。
+
+　　比如睡前刷手机。手机在枕头边，充电线也在枕头边，伸手拿过来就能看；想读的书却在客厅，得起床、开灯、找一找。
+
+　　最后又刷了半个小时，于是得出结论：我这个人，就是没有自制力。
+
+　　先等等。你把一边的路铺到了床上，另一边还得翻个栏杆，再来比较自己喜欢往哪边走，这个结果能说明多少问题？
+
+　　我觉得，很多改习惯的计划，太急着审判人了。
+
+　　还没弄清楚一件事为什么会反复发生，就先给自己定性。懒，浮躁，没毅力。定性之后再来一场热血沸腾的自我动员，决定明天彻底改变。
+
+　　然后手机继续放在枕头边。
+
+　　当然，手机不会自己爬进手里，人也不是完全受摆布的。但既然你已经知道，晚上累的时候容易顺手拿起来，为什么还要把每天的成败，都押在那一刻能不能克制上？
+
+　　**能提前挪一下位置的事情，没必要留到每次动手前，再跟自己辩论一遍。**
+
+　　假设你只是想在睡前少刷一会儿，可以试着把充电的位置挪到卧室门口，书放到床头。没有规定今晚必须读多少页，也不需要把所有娱乐软件删干净。
+
+　　只改一个地方：想继续刷，就得起身去拿。
+
+　　这个动作未必能拦住你。真想看，几步路算什么。但它能让原本连想都不用想的动作，变成一次需要决定的行动。
+
+　　手往枕头边一摸，没摸到，这时候才有机会问一句：我现在确实想看点什么，还是只是习惯性地拿一下？
+
+　　如果确实想看，拿回来就是了。这也不意味着尝试失败，你至少知道了，今天这几步路拦不住这个需求，得再看看自己到底想从手机里得到什么。
+
+　　是跟朋友聊天，还是白天一直没有自己的时间，只想在晚上补一点回来？如果是后者，把手机挪远并不会替你腾出白天的空闲。
+
+　　所以调整位置能解决一部分问题，也只能解决一部分。别把它用成另一个证明自己不行的考试。
+
+　　反过来也一样。想多做的事，可以先让它容易开始。
+
+　　打算练字，纸笔却收在柜子深处，每次都得清桌子、找垫板、倒墨水，练字之前还附送一套准备工作。哪天只有十分钟空闲，光想到这些就不想动了。
+
+　　如果桌上留一支能直接用的笔和几张纸，坐下就能写两行，至少不用等到有一整段时间，才有资格开始。
+
+　　两行当然不能保证字变好。字写得好不好，仍然得看怎么练、有没有发现问题。但连笔都没拿起来的时候，先解决拿笔这一步，并不丢人。
+
+　　不过，把纸笔摆出来以后，也得看自己是不是真的多写了几次。如果一直没碰，就该问问，是放的位置仍然不方便，还是自己根本不想练，只是觉得字好看的人很让人羡慕。
+
+　　判断很简单。改完之后，下次做这件事，究竟少了哪一步？如果说不出来，只是看起来更像一个认真练字的人，那大概还没改到地方。
+
+　　也不用把家里所有东西都按“培养好习惯”的标准重新摆一遍。客厅是几个人共用的，就不能为了自己拿书方便，把别人的东西全收走。你少走的几步，不该变成别人每天多做的家务。
+
+　　手机也是，有人晚上需要接重要来电，就得保留听得到、找得到的安排。改变习惯终究是为了方便生活，没必要把生活改造成一场处处设卡的训练。
+
+　　我更愿意从一个已经反复出现的动作开始看：做之前，手先伸向哪里？想做的事情，又是在哪一步被嫌麻烦了？
+
+　　找到那个地方，做一点小调整，过几天看看。看的是睡前有没有少刷一会儿、空闲时有没有拿起笔，不是房间布置得有多漂亮。如果没用，就再改，不必马上升级成对人格的批判。
+
+　　你仍然可以选择刷手机，也可以选择今天不练字。只是下次准备责怪自己之前，不妨先看一眼床头和桌面。
+
+　　有时候，先挪一根充电线，比再发一次誓更有用。
+

+# 家务只分到动手，安排家务的人就没下班
+
+<!-- daily-essay-id: 2026-10-04 -->
+
+「你叫我做就好了嘛。」这句话听上去很配合，但说完之后，另一个人多半还是休息不了。
+
+　　假设两个人一起住，说好了一个做饭，一个买菜。到了下午，负责买菜的人发来消息：今晚吃什么？买多少？家里还有没有鸡蛋？这个牌子没有，换哪个？
+
+　　每个问题都不大，回一句就行。可负责做饭的人刚坐下来，就要在脑子里翻一遍冰箱，算一遍晚上的时间，再把另一半工作安排出去。
+
+　　菜确实不是他买的。但这顿饭从头到尾该怎么发生，依然得由他想着。
+
+　　等他抱怨累，对方也委屈：我都出门跑了一趟了，你怎么还不满意？
+
+　　两个人可能都没撒谎。一个承担了动作，另一个承担了让这些动作按时发生的责任。把前者分出去，后者未必就跟着分出去了。
+
+　　做一件家务，往往从动手之前就开始了。发现洗衣液快没了，记住要补，判断今天是不是得洗衣服，留出晾晒的位置，这些都没有洗衣机转起来那么显眼。
+
+　　可是漏掉其中一件，衣服就可能洗不成。到那时，谁会被问「你怎么没提醒我」？谁就还在负责。
+
+　　我觉得，判断家务有没有分出去，有个很直接的办法：**其中一个人不再提醒，这件事还能不能正常完成？**
+
+　　如果不能，那现在分出去的可能只是几道工序。负责的人还得随时待命，等着回答问题、发出指令、检查有没有做完。
+
+　　这跟工作里带新人有点像。你把操作交给他，自己仍然得盯进度、查遗漏，当然可以叫分工，但不能指望立刻省心。带新人还有一个逐渐独立的过程，一起生活却不能永远停在「你说我做」这一步。
+
+　　所以我更倾向于，把一小件事完整地交出去。
+
+　　比如买菜，不妨连着家里现有的食材、这周要补什么、东西买回来放在哪里，一起交给负责采购的人。做饭的人提供必要的信息：哪天不在家，什么东西不能吃，哪些食材自己不会处理。
+
+　　两个人需要商量的，是共同吃什么、花多少钱。至于家里还剩几颗鸡蛋，总不至于只有一个人有资格打开冰箱看吧。
+
+　　刚开始不熟悉，问一问很正常。问题在于，问过之后有没有慢慢接过去，还是每次都把同一份判断原封不动地送回来。
+
+　　当然，说到这里，习惯安排的人也有一件不太舒服的事要做：允许对方真的拿主意。
+
+　　你不能一边希望他独立负责，一边要求他每一步都照自己的习惯来。纸巾必须买同一个牌子，毛巾必须折成同一个方向，晚饭必须按自己临时冒出来的想法改，最后对方自然会事事请示。
+
+　　毕竟不请示就要返工，谁还愿意自己判断。
+
+　　这时候得把要求摊开。预算、过敏、基本卫生，这些该说清楚；自己单纯喜欢什么，也可以提，但要承认那是偏好，未必是唯一合格的做法。
+
+　　把责任交给别人，多少要接受事情做得跟自己不一样。要是某个细节实在放不下，就把它留下来自己做，再换掉另一件事。总比嘴上说随便，做完又从头挑一遍好。
+
+　　反过来，接手的人也不能拿「你别管」当作敷衍的理由。
+
+　　说好负责洗衣服，却总拖到别人没有干净衣服可穿；说好采购，缺了东西就等另一个人顺路买回来，这都谈不上独立负责。出了遗漏，补上的那一步也该由自己接着做。
+
+　　否则对方放手一次，吃亏一次，下次只会盯得更紧。
+
+　　也不必把所有家务都切得整整齐齐。有的人确实擅长统筹，另一个人愿意多做些具体的活，这样分完全可以。前提是双方都承认，安排本身占用时间，也该算进各自的付出里。
+
+　　至于小孩、生病的家人，或者临时特别忙的人，能承担多少就商量多少。分工要照顾实际能力，没必要拿一套标准追着所有人跑。
+
+　　如果你想让一起生活的人歇一会儿，下次可以少问一句「还有什么要我做的」，先接下一件自己熟悉的小事。从发现需要做，到最后收拾完，都由自己记着。
+
+　　哪怕只是补齐洗漱用品。让对方有几天完全不用想家里还剩多少牙膏，这份家务才算真的从他脑子里搬出去了。
+

+# 养成好习惯
+
+*梁实秋*
+
+　　人的天性大致是差不多的，但是在习惯方面却各有不同，习惯是慢慢养成的，在幼小的时候最容易养成，一旦养成之后，要想改变过来却还不很容易。
+
+　　例如说：清晨早起是一个好习惯，这也要从小时候养成，很多人从小就贪睡懒觉，一遇假日便要睡到日上三竿还高卧不起，平时也是不肯早起，往往蓬首垢面的就往学校跑，结果还是迟到，这样的人长大了之后也常是不知振作，多半不能有什么成就。祖逖闻鸡起舞，那才是志士奋励的榜样。
+
+　　我们中国人最重礼，因为礼是行为的轨范。礼要从家庭里做起。姑举一例：为子弟者“出必告，反必面”，这一点点对长辈的起码的礼，我们是否已经每日做到了呢？我看见有些个孩子们早晨起来对父母视若无睹，晚上回到家来如入无人之境，遇到长辈常常横眉冷目，不屑搭讪。这样的跋扈乖戾之气如果不早早的纠正过来，将来长大到社会服务，必将处处引起摩擦不受欢迎。我们不仅对长辈要恭敬有礼，对任何人都应维持相当的礼貌。
+
+　　大声讲话，扰及他人的宁静，是一种不好的习惯。我们试自检讨一番，在别人读书工作的时候是否有过喧哗的行为？我们要随时随地为别人着想，维持公共的秩序，顾虑他人的利益，不可放纵自己，在公共场所人多的地方，要知道依次排队，不可争先恐后的去乱挤。
+
+　　时间即是生命。我们的生命是一分一秒的在消耗着，我们平常不大觉得，细想起来实在值得警惕。我们每天有许多的零碎时间于不知不觉中浪费掉了。我们若能养成一种利用闲暇的习惯，一遇空闲，无论其为多么短暂，都利用之做一点有益身心之事，则积少成多终必有成。常听人讲过“消遣”二字，最是要不得，好像是时间太多无法打发的样子，其实人生短促极了，哪里会有多余的时间待人“消遣”？陆放翁有句云：“待饭未来还读书。”我知道有人就经常利用这“待饭未来”的时间读了不少的大书。古人所谓“三上之功”，枕上、马上、厕上，虽不足为训，其用意是在劝人不要浪费光阴。
+
+　　吃苦耐劳是我们这个民族的标帜。古圣先贤总是教训我们要能过得俭朴的生活，所谓“一箪食，一瓢饮”，就是形容生活状态之极端的刻苦，所谓“嚼得菜根”，就是表示一个有志的人之能耐得清寒。恶衣恶食，不足为耻，丰衣足食，不足为荣，这在个人之修养上是应有的认识，罗马帝国盛时的一位皇帝，Marcus Aurelius，他从小就摒绝一切享受，从来不参观那当时风靡全国的赛车比武之类的娱乐，终其身成为一位严肃的苦修派的哲学家，而且也建立了不朽的事功。这是很值得钦佩的，我们中国是一个穷的国家，所以我们更应该体念艰难，弃绝一切奢侈，尤其是从外国来的奢侈。宜从小就养成俭朴的习惯，更要知道物力维艰，竹头木屑，皆宜爱惜。
+
+　　以上数端不过是偶然拈来，好的习惯千头万绪，“勿以善小而不为”。习惯养成之后，便毫无勉强，临事心平气和，顺理成章。充满良好习惯的生活，才是合于“自然”的生活。

+# 把问题说清楚，是求助者该做的那一半
+
+<!-- daily-essay-id: 2026-10-03 -->
+
+求人帮忙的时候，把问题说清楚，应该算在自己的工作里。
+
+　　比如你准备找工作，把一份简历发给朋友，附上一句：“有空帮我看看。”朋友打开之后，第一件事就卡住了：看什么？
+
+　　看错别字，还是看排版？准备投哪个岗位？是完全没有面试机会，还是有面试但总过不了？你有十年工作经历，和你刚毕业，需要看的地方可能完全不同。
+
+　　这些信息你都知道，但朋友不知道。他得先挨个问一遍，才轮得到帮忙。
+
+　　你觉得自己只提了一个小请求，对方接到手里，却要先做一轮访谈。
+
+　　很多求助就是在这里变得费劲的。发消息的人怕麻烦别人，于是把话缩得特别短，觉得这样显得客气。接消息的人反而要花更多时间，才能弄清楚到底要干什么。
+
+　　少打几个字，未必少占用别人几分钟。
+
+　　当然，向熟悉的朋友随口问一句，没必要像提交申请一样严肃。但如果确实需要对方动脑子、花时间，至少要让他知道，自己的力气该往哪儿使。
+
+　　还是那份简历。如果你补一句：“我准备投这类岗位，最近几次都没进面试。想请你看看项目经历有没有写清楚，排版我自己改。”再把对应的招聘要求一起发过去，朋友就有地方下手了。
+
+　　他也能判断这是不是自己帮得上的忙。没做过相关工作，可以直接说不熟；只方便看一段，也可以先看一段。你们不用在“你先发来吧”和“你觉得怎么样”之间来回试探。
+
+　　**好的求助，会让对方更容易判断自己能做什么。**
+
+　　这件事还有一个不太讨喜的部分：有时你以为自己缺一个答案，实际上连想问什么都还没想清楚。
+
+　　“这个方案好不好？”听起来是个问题，可什么叫好？更省钱，还是更省事？能马上做，还是以后方便改？如果几样不能兼得，你愿意先保哪一样？
+
+　　这些取舍一直悬着，再有经验的人也只能给你罗列可能性。等他讲了一大堆，你再逐条补充“但我这里还有个情况”，两个人都会累。
+
+　　不妨在发出去之前，自己先写几句：准备做什么，现在卡在哪里，已经试过什么。写到第三句才发现，原来缺的是一个还没确认的日期，那就先去确认日期。
+
+　　不过，这不能变成另一种门槛。不能要求求助的人先把所有事搞懂，才配开口。真能独立梳理到那个程度，可能也就不需要帮忙了。
+
+　　完全没头绪也可以直说：“我连从哪里查起都不知道，能不能帮我判断一下，第一步该看什么？”
+
+　　这已经很清楚了。你想借用对方的经验，找到入口。对方愿意的话，带你梳理一遍也没问题。
+
+　　我觉得最容易让人疲惫的，是那个没说出来的要求：你替我想清楚，替我选好，最好最后出问题也别让我后悔。
+
+　　比如问朋友要不要换一份工作，朋友可以帮你分析具体条件，却很难替你决定每天多花一小时通勤值不值得。路要你自己走，他没法代替你感受那一小时。
+
+　　把自己的在意之处说出来，建议才有机会落到你的生活里。听完以后怎么选，也仍然需要你来决定。
+
+　　还有，问题说得清楚，不代表对方就欠你一个回答。消息整理得再认真，对方也可能没空、没兴趣，或者不愿意承担这份责任。
+
+　　把请求范围缩小，给对方留出拒绝的余地，都只能让一次合作更容易发生，不能保证合作一定发生。这点最好提前想好，否则很容易觉得：“我都这么客气了，你怎么还不帮？”
+
+　　客气到最后成了催债，前面的体谅也就白费了。
+
+　　反过来，帮忙的人如果答应只看项目经历，你也别等他看完，再顺手追加排版、投递策略和模拟面试。新的请求，值得重新问一次。
+
+　　有些忙越帮越大，就是因为每一步都被说成“顺便”。
+
+　　下次准备发“帮我看看”之前，可以先补上你最想让对方看的那一处。如果连那一处都找不到，就把“找不到问题在哪儿”说出来。
+
+　　让对方打开消息时，就知道你正站在哪里、希望他帮哪一步。剩下的，再看彼此愿不愿意、方不方便。
+

+# 谈海明威
+
+*加西亚.马尔克斯*
+
+　　我一眼就把他认出来了，那是 1957 年巴黎一个春雨的日子，他和妻子玛丽·威尔许经过圣米榭勒大道。他在对街往卢森堡公园的方向走，穿着破旧的牛仔裤、格子衬衫，戴一顶棒球帽。惟一看起来跟他不搭调的是一副小圆金属框眼镜，仿佛很年轻就当上祖父似的。他已经 59 岁了，体格壮硕，想不看见都不行，他无疑想表现出粗犷的味道，可惜没有给人这种感觉，他的臀部很窄，粗糙的伐木靴上方是一双略显瘦削的腿。在旧书摊和索邦大学出来的大批学子当中，他显得生气蓬勃，想不到四年后他就去世了。
+
+　　好像总是这样，在一刹那间，我发现自己被分成了两个角色，而且在相互竞争。我不知道该上前去请他接受访问，还是过街去向他表达我对他无限的景仰。但不管怎么做对我来说都很不容易。当时我和现在一样，说得一口幼稚园英语，也不清楚他的斗牛士西班牙语说得怎么样。为了不要破坏这一刻，我两样都没做，只像人猿泰山那样用双手圈在嘴巴外面，向对街的人行道大喊：“大——大——大师！”海明威明白在众多学生中不会有第二个大师，就转过头来，举起手用卡斯蒂亚语像小孩子似地对我大叫：“再见，朋友！”以后我再也没见过他。
+
+　　当时我 28 岁，是报社从业人员，在哥伦比亚出版过一本小说，得了一个文学奖，可是仍在巴黎漫无目的地飘荡着。我景仰的大师是两位极为不同的北美洲小说家。当年他们的作品只要出版过的我一律没放过，但我不是把他们当作互补性的读物，而是两种南辕北辙截然不同的文学创作形式。一位是威廉·福克纳，我一直无缘见到他，只能想像他是卡尔迪埃·布勒松拍的那张著名肖像中的模样，在两只白狗旁边，穿着衬衫在手臂上抓痒的农夫。另一位就是在对街和我说再见，立刻又消失在人群中的人，留给我一种感觉，曾经有什么已经出现在我的生命里，而且从来没有消失过。
+
+　　不知道是谁说过，小说家读其他人的小说，只是为了揣摩人家是怎么写的。我相信此言不假。我们不满意书页上暴露出来的秘诀：甚至把书翻过来检查它的接缝。不知道为什么，我们把书拆到不能再拆，直到我们了解作者个人的写作模式，再装回去。但这样分析福克纳的小说，就未免令人气馁，他似乎没有一个有机的写作模式，反而是在他的圣经世界里瞎闯，仿佛在一个摆满水晶的店里放开一群山羊。分解他的作品，感觉就像一堆剩下的弹簧和螺丝，根本不可能再组合成原来的样子。对比之下，海明威虽然比不上福克纳的发人深省、热情和疯狂，却严谨过人，零件就像货车的螺丝一样看得清清楚楚。也许就因为这样，福克纳启发了我的灵魂，海明威却是对我的写作技巧影响最大的人——不仅是他的著作，还有他对写作方法与技巧的惊人知识。《巴黎评论》登的那篇他和乔治·普林顿历史性的访谈中，他揭示了一套和浪漫时期创作理念相反的说法：经济的不虞匮乏和健康的身体对写作有帮助；最大难题就是把文字配置妥当；当你觉得下笔不如过去容易，应该重读自己的作品，好记起写作从来不是一件容易的事；只要没有访客和电话，哪里都可以写作；常有人说新闻会扼杀一个作家，其实正好相反，只要能赶快把新闻那一套丢开，倒可以成就一个作家。他说：“一旦写作上了瘾，成为最大的乐趣，不到死的那天是不会停笔的。”最后他的经验发现，除非知道第二天要从哪里接下去，否则不能中断每天的工作。我认为这是对写作最有用的忠告。作家最可怕的梦魇就是早上面对空白稿纸的痛苦，他这番话无异于一贴万灵丹。
+
+　　海明威的作品全都显现了他如昙花一现般灿烂的精神。这是可以理解的。他对技巧那种严格的掌控所建构出的内在张力，在长篇小说广泛而冒险的范围中无法维系下去。这是他出类拔萃的特质，也是他不该企图逾越的局限。就因为如此，海明威的余文赘语比其他作家的更显眼，他的小说就像是写过了头，比例不相称的短篇小说。对比之下，他的短篇小说最大的优点就是让你觉得少了什么，这也正是其神秘优美之所在。当代大作家博尔赫斯也有同样的局限，但他懂得不要贸然逾越。
+
+　　弗朗西斯·麦康伯一枪射死狮子，可以说给读者上了一堂打猎课，但也正是写作方法的总结。海明威在一篇短篇小说中描写一头来自里瑞亚的公牛，从头牛士胸前擦过，又像“转角的猫”似地快速跑回来。容我斗胆一言，我相信这样的观察，就是那种最伟大的作家才会冒出来的傻气小灵感。海明威的作品充满了这种简单而令人目眩的发现，显示此时他已经调整了他对文学写作的定义：文学创作犹如冰山，有八分之七的体积在下面支撑，才会扎实。
+
+　　对技巧的自觉无疑是海明威无法以长篇小说著称，而以较工整的短篇小说扬名立万的理由。谈到《丧钟为谁而鸣》，他说并没预先计划好故事架构，而是每天边写边想。这用不着他说，看也看得出来。对比之下，他那些即兴创作的短篇小说却无懈可击。就像某个 5 月天因为暴风雪，使得圣伊西德罗庆典的斗牛表演被迫取消，那天下午他在马德里的自助式公寓写了三个短篇小说，据他自己跟乔治·普林顿说，这三篇分别是《杀人者》、《十个印第安人》和《今天是星期五》，全都非常严谨。照这样说来，我个人觉得他的功力最施展不开的作品是短篇小说《雨中的猫》。
+
+　　虽然这对他的命运似乎是一大嘲讽，我倒觉得他最迷人最人性的作品就是他最不成功的长篇小说：《过河入林》。就像他本人透露的，这原本是一篇短篇小说，不料误打误撞成了长篇小说，很难理解以他如此卓越的技巧，会出现这么多结构上的缺失和方法上的错误，极不自然，甚至矫揉造作的对话，竟然出自文学史上的巨匠之一。此书在 1950 年出版，遭到严厉批评，但这些书评是错误的。海明威深感伤痛，从哈瓦那发了一封措词激烈的电报来为自己辩护，像他这种地位的作家，这么做似乎有损颜面。这不只是他最好的作品，也是最具个人色彩的长篇小说。他在某一秋天的黎明写下此书，对过往那些一去不回的岁月带着强烈的怀念，也强烈地预感到自己没几年好活了。他过去的作品尽管美丽而温柔，却没有注入多少个人色彩，或清晰传达他作品和人生最根本的情怀：胜利之无用。书中主角的死亡表面上平静而自然，其实变相预示了海明威后来以自杀终结自己的一生。
+

+# 连绵的城市
+
+*伊塔洛.卡尔维诺*
+
+　　要跟你讲潘特熙莱雅，就得从描述城市的入口开始。你一定会想象，在尘土飞扬的平原上会看见远处一堵城墙拔地而起，你一步步走近城门，守在门边的收税官已经在斜眼观察你的行囊。在你走进城门之前，你还是在城外；穿过拱形门洞，你便发觉自己已经在城里了。城墙的厚度包围着你，城墙的石头上有刻痕，只要你跟踪它那粗糙的线条，就能看出某种图形来。

+

+
