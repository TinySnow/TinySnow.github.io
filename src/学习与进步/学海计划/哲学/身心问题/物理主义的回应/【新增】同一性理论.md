## 正文

　　本文讨论：哲学-身心问题-物理主义的回应-同一性理论。

　　行为主义因为把“内在”丢了而失分，同一性理论偏偏反着来，直接冲着“内在”走过去。它的口号很短：心理状态就是脑状态。它不谈“引起”，也不谈“相关”，说的就是直接等同。

　　具体的说法通常是这样：疼痛，就是 C 神经纤维的放电活动。正像水就是 H₂O，闪电就是大气里的放电。你日常挂在嘴边的“疼”，和神经科学术语里的“某类特定脑活动”，指的是同一个东西，只是用了两套话去说。

<br />

　　同一性理论的好处一眼可见。

　　第一，它简单。不需要假设任何非物理的东西，本体论账单上干干净净。

　　第二，它有科学撑腰。神经科学不断发现特定心理功能和特定脑区的紧密关联：海马体和记忆，杏仁核和恐惧，前额叶和决策。要是什么时候这些关联都能在最直接的层面被解释，同一性理论省下的力气最多。

　　它内部还分粗细。类型同一性说，“疼痛”这一整类心理状态，对应“某一类”脑状态；令牌同一性只承认，每一次具体的疼，对应一次具体的脑活动，不保证所有的疼都长一个样。前者赌得大，容易被多重可实现性将死；后者保守，解释力也弱一些。这个区分第一次听会绕，却是理解后面争论的钥匙。

<br />

　　麻烦也来得很快，最经典的一条叫多重可实现性。

　　假设疼痛就是 C 神经纤维放电，那凡是没有 C 神经纤维的生物，是不是就不可能疼？章鱼的神经结构跟人差着十万八千里，可它被烫到会缩、会喷墨，我们强烈地倾向于说它疼。再往远处推，一个行为上、功能上跟人没差的 AI，只因为它没有 C 神经纤维，就不算真疼吗？

　　如果答案都是“不算”，同一性理论就带着一股碳基沙文主义的味道：只有特定生物结构才配拥有心灵。这个结论多数人下不去嘴。

<br />

　　还有一条批评来自“同一个东西”这个说法本身。同一是必然的，水是 H₂O 这件事，在任何可能世界里都成立。可“疼痛等于某束神经放电”听起来像是一个经验发现，而不是一条逻辑真理。要真是同一，凭什么它显得像碰巧？支持者的回法是：水与 H₂O 当初也显得像碰巧，后来就不觉得了。疼痛与脑状态大概也会走同一条路。

　　还有一点也添乱。疼痛并不总对应组织损伤。慢性疼痛、幻肢痛、安慰剂效应，都能在没有相应损伤的时候让人真真切切地疼。这让“疼就是某束纤维放电”这句话变复杂了：纤维放电可能是疼的必要环节，却不一定等于疼的全部。

　　支持者也不是完全没话说。他们可以退一步，说疼痛不一定就是 C 纤维，而是“某类”脑状态，具体是哪类，交给科学去填。这样类型同一性就松了绑，但也模糊了它一开始最吸引人的那份干脆。

<br />

　　也是因为多重可实现性，不少哲学家从同一性理论转向了功能主义。心理状态不该用“它是什么做的”来定义，而该用“它做什么”来定义。

　　这一步转得合不合理，取决于你怎么看“做同样的事”。章鱼和人都缩手，背后的东西真的算“同一件事”吗，还是只是像？这个问题，功能主义那一篇还会接着吵。

<br />

　　还有个现实里的对照。医生用 fMRI 看脑活动，能大致判断你是在看人脸还是看风景，可他说不出你此刻高不高兴。同一性理论赌的是，这种说不出只是暂时的，不是原则性的。

　　我自己的感觉是，同一性理论最诚实。它不绕弯子，直接把赌注押在“疼就是脑活动”上，输了也认得干脆。怕就怕它押得太死，把宇宙里可能有的其他会疼的东西，一并关在了门外。

　　最后补一句，这条理论真正的对手未必是哲学，而是科学自己。哪一天神经科学能指着某片脑区说“疼就在这儿，别的都不是”，它才算真正落地。
