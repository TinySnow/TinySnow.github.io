# 附录：术语表

　　本表收录第 48～100 章已经出现、适合回查的操作系统术语。它只充当地图，不替代正文中从问题到机制的过程。

| 术语 | 简要说明 |
| --- | --- |
| 固件 | 保存在非易失性存储器中的启动软件。 |
| 引导程序 | 负责找到、装入并转交控制权给内核的启动阶段程序。 |
| 内核 | 操作系统中直接管理关键硬件和共享资源的核心部分。 |
| 用户态 | 普通应用运行的受限 CPU 状态。 |
| 内核态 | 可执行特权指令、操作受保护资源的 CPU 状态。 |
| 系统调用 | 应用安全请求内核服务的受控入口。 |
| 进程 | 一份正在运行的程序及其执行现场、地址空间和资源。 |
| 线程 | 进程内部的一条执行线，拥有自己的栈和寄存器现场。 |
| PCB | 进程控制块；内核记录一个进程状态和资源的档案。 |
| 就绪 | 已具备运行条件、正在等待 CPU 的进程状态。 |
| 阻塞 | 正在等待 I/O 或其他事件、暂时不能继续的进程状态。 |
| 上下文切换 | 保存当前执行现场并恢复另一个现场的过程。 |
| 调度 | 从就绪任务中选择谁使用 CPU 的决策过程。 |
| 时间片 | 抢占式调度中允许任务连续运行的最长时间段。 |
| 并发 | 多项工作在时间上交错推进。 |
| 并行 | 多项工作在多个核心上同时执行。 |
| 进程间通信 | 隔离进程之间交换数据或通知的机制。 |
| 临界区 | 访问共享资源、不能被多个执行者同时进行的代码段。 |
| 原子操作 | 对外表现为不可分割的一步操作。 |
| 互斥锁 | 保证同一时刻只有一个执行者进入临界区的锁。 |
| 条件变量 | 让线程等待某个条件成立、并在状态变化时被通知的机制。 |
| 信号量 | 用计数表示可用资源数量的同步机制。 |
| 死锁 | 各执行者相互等待资源，导致系统无法推进的状态。 |
| 虚拟地址 | 程序使用的地址，需要翻译后才对应物理内存。 |
| 地址空间 | 一个进程可见的虚拟地址范围及其映射规则。 |
| 页 | 分页系统中固定大小的虚拟内存单位。 |
| 页框 | 物理内存中与页同样大小的固定单位。 |
| 页表 | 记录虚拟页与物理页框对应关系及权限的结构。 |
| TLB | 缓存近期页表项、加速地址转换的硬件缓存。 |
| 缺页异常 | 访问的虚拟页未驻留内存时触发的异常。 |
| 交换空间 | 为暂时不在内存中的页面提供后备存储的区域。 |
| 页面置换 | 内存不足时选择一个驻留页换出以腾出页框的过程。 |
| 工作集 | 进程在一段近期时间内活跃使用的页面集合。 |
| 写时复制 | 先共享页面，首次写入时才复制的优化。 |
| 设备控制器 | 连接 CPU/内存与具体设备、执行设备协议的硬件。 |
| 驱动程序 | 向内核隐藏具体设备差异的软件。 |
| DMA | 控制器直接在设备和内存间传输数据的机制。 |
| 文件描述符 | 进程持有的、指向已打开文件或 I/O 对象的小整数句柄。 |
| inode | 记录文件属性及数据块位置的一类元数据结构。 |
| 页面缓存 | 内核保存的近期文件页面缓存。 |
| 内存映射 | 将文件或共享页映射进进程地址空间的机制。 |
| 崩溃一致性 | 断电或故障中断更新后，持久数据仍可恢复的性质。 |
| 日志文件系统 | 先记录可恢复的修改意图，再更新真实结构的文件系统。 |
| 访问控制 | 根据身份和规则决定是否允许访问资源。 |
| 虚拟机 | 提供近似完整独立计算机环境的隔离边界。 |
| 容器 | 共享宿主内核、隔离进程环境和资源视图的机制。 |
