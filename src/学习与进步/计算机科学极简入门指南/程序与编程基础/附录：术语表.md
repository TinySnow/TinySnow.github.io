# 附录：术语表

　　本表收录第 36～47 章已经出现、适合随时回查的词。它不是新的课程；遇到不熟悉的词时可以回来查，仍以正文中的例子和推导为准。

| 术语 | 简要说明 |
| --- | --- |
| 机器语言 | CPU 能直接执行的二进制指令序列。 |
| 指令集 | 一台 CPU 规定可执行的指令及其编码、操作数规则的集合。 |
| 汇编语言 | 用助记词、寄存器名和符号地址书写的低层语言。 |
| 助记词 | 例如 `LOAD`、`ADD` 的短名称，用于提示对应的机器指令。 |
| 汇编器 | 把汇编语言转换为机器码的工具。 |
| 符号 | 源程序中代表地址的名称，例如变量名和标签。 |
| 标签 | 标记一条指令位置的符号，常作为跳转目标。 |
| 高级语言 | 更接近问题描述、隐藏较多机器细节的编程语言。 |
| 变量 | 可用名字读写的值；运行时会对应寄存器或内存中的位置。 |
| 类型 | 规定一串位如何解释，以及允许进行哪些操作的规则。 |
| 表达式 | 根据常量、变量和运算符计算出一个值的结构。 |
| 赋值 | 先计算右侧表达式，再把结果保存到左侧变量的动作。 |
| 分支 | 根据条件选择不同执行路径的控制结构。 |
| 循环 | 在条件满足时重复执行一段代码的控制结构。 |
| 函数 | 接受输入、完成一项命名任务，并可交回结果的代码单元。 |
| 参数 | 调用函数时交给函数的输入。 |
| 返回值 | 函数完成后交给调用者的结果。 |
| 返回地址 | 函数结束后应继续执行的指令位置。 |
| 运行栈 | 按后进先出方式保存调用现场的一片内存区域。 |
| 栈帧 | 一次函数调用在运行栈上占用的记录，通常含局部变量和返回地址。 |
| 堆 | 运行时按需申请、生命周期不必等同于函数调用的内存区域。 |
| 源代码 | 程序员写下的、尚未变成目标机器指令的程序文本。 |
| 编译器 | 把高级语言转换为较低层程序表示的工具。 |
| 目标文件 | 已含机器码但可能仍有外部引用、尚未完整组合的文件。 |
| 链接器 | 组合目标文件和库，解决外部引用并生成最终程序的工具。 |
| 可执行文件 | 可被装载并从入口启动的程序包。 |
| 解释器 | 在运行时读取并执行另一份程序含义的程序。 |
| 字节码 | 介于源代码与本机机器码之间、常由虚拟机处理的中间指令形式。 |
| 裸机程序 | 不依赖操作系统、直接面对硬件运行的程序。 |
