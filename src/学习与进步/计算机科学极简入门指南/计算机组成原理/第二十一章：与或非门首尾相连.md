# 与或非门首尾相连

## 复习

- 算术逻辑单元：ALU 把算术和逻辑运算集成起来，用操作码选择当前运算
- ALU 的状态标志：ALU 用零、符号、进位和溢出标志记录运算结果的特征
- 运算器总装：把前面造好的零件组装成了能算加减乘除的运算器

## TL;DR

- 反馈让电路的输出影响后续输入，但不同连接方式的结果不同
- 合理的交叉耦合可以形成稳定的记忆；不合适的组合反馈可能没有稳定状态或产生振荡

## 正文

### 引言

　　到目前为止，我们已经了解了计算机如何进行运算：通过 ALU 执行各种算术和逻辑操作。ALU 是 CPU 中负责计算的部件；CPU 里的控制器和寄存器还需要后面的知识才能造出来。接下来，我们先将目光瞄向存储中间结果的存储器。

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/technology/computer-science-guide/content/von_neumann-architecture.webp)

### 需要存储的理由

　　想象一下，如果计算机只有 ALU 而没有存储功能：

1. 不能保存中间结果
2. 不能记住程序状态
3. 不能存储用户数据
4. 每次都要重新输入数据
5. 一旦输入错误就完蛋了

　　所以，存储功能和运算功能一样重要。

### 首尾相连？

　　之前制造的所有部件，数据都是向前流动的，为什么没有人想到将它首尾相连呢？

### 非门首尾相连

　　让我们看一个最简单的例子：一个非门的输出连接到它自己的输入。

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/not-gate-feedback.png)

　　在理想的数字逻辑里，这条反馈写成 `Q = Q̅`，没有任何一个稳定的 0 或 1 能满足它。真实电路还会受到传播延迟和模拟特性的影响，输出行为并不受控，不能把这个单门回路当成可靠的振荡器或时钟。

　　真正的环形振荡器至少会使用奇数个非门，并利用传播延迟产生翻转；实际计算机时钟通常还要用晶体、RC 电路或锁相环来获得稳定频率。这里先记住：**组合逻辑形成反馈时，必须格外小心。**

### 与门和或门首尾相连

　　我们再看与门和或门。

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/trigger-and.gif)

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/trigger-or.gif)

　　与门回路可以写成 `Q = Q AND X`：当 X 为 0 时，它把 Q 清成 0；当 X 为 1 时，它保持 Q。或门回路则相反：当 X 为 1 时，它把 Q 置成 1；当 X 为 0 时，它保持 Q。

　　它们只能朝一个方向改变状态，不能自由地写入 0 和 1，因此还不是实用的存储单元。与非门、或非门等反馈组合也不能一概而论，有些输入组合没有稳定状态。

　　要做出真正可控的“记忆”，需要把两个门交叉耦合，并为写入 0、写入 1 和保持状态分别设计规则。

### 记忆？

　　如果我们能够控制这种“自己的输出又变成输入”的反馈，让电路保持在某个稳定状态，同时又能按需要写入 0 或 1，会不会更好一些？
