# 锁存器

## 复习

- ALU 的状态标志：ALU 用零、符号、进位和溢出标志记录运算结果的特征
- 运算器总装：把前面造好的零件组装成了能算加减乘除的运算器
- 与或非门首尾相连：合理的交叉耦合反馈可以形成稳定状态，组合反馈也可能不稳定

## TL;DR

- 锁存器由一些基础逻辑门组成，不同的是，他们之间有首尾连接的现象
- 锁存器是最简单的记忆单元
- 本章先用复位优先锁存器说明反馈，再介绍标准 SR 锁存器和 D 锁存器

## 正文

### 锁存器：最简单的记忆电路

　　上一章看到，只有合理设计的反馈才能形成稳定状态。那么把逻辑门交叉耦合起来，能否做成一个可控的记忆电路，进而控制写入和输出呢？

　　可以试一下。

### 复位优先锁存器

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/SR-Latch.gif)

　　上面这个由 3 个逻辑门构成的锁存器，叫 AND-OR 锁存器。它有置位和复位两个输入，但复位优先：当两个输入同时有效时，输出会复位为 0。

　　标准 SR 锁存器则由两个门交叉耦合而成。下面这张图使用 2 个与非门（NAND），逻辑门更少，但看起来更复杂。

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/SR-Latch-2与非.png)

　　注意：下面图中输入的是 S 和 R 的反相，即 S' 和 R'。当 S' 为 0 时置位，当 R' 为 0 时复位。输出有两个值，一个为 Q，另一个 Q_Not 为 Q 的反相；若 S' 和 R' 同时为 0，两个输出都会变成 1，失去互补关系，解除这个状态后结果可能不确定。

　　看起来很晕对不对？所以为了保持简洁，之后还是使用上面的图。实际 CPU 的存储单元还会使用传输门、反相器和专用标准单元等结构，不一定是这里的任一种电路。

#### 输入

- S（Set）：设置输出为 1，除非 Reset 改变
- R（Reset）：将输出复位，设置为 0

#### 真值表

| S | R | Q(下一状态) | 说明 |
|:-:|:-:|:----------:|:-----|
| 0 | 0 | Q(保持) | 保持当前状态 |
| 0 | 1 | 0 | 复位 |
| 1 | 0 | 1 | 置位 |
| 1 | 1 | 0 | 复位优先 |

> 　　当 S = 1、R = 1 时，这个锁存器的输出是什么？为什么？

### D 锁存器

　　用 Set 和 Reset 控制输出，感觉有些复杂，锁存器多起来之后很容易晕。

　　有没有什么办法，能使输入简明一些呢？比如是否启用锁存器（Enable）？

![](https://raw.githubusercontent.com/TinySnow/GithubImageHosting/main/blog/computer-science-guide/content/D-Latch.gif)

　　增加了两个与门、一个非门和两个输入：数据 D（Data） 及输入启用线 WE（Write Enable，或写为门控 G，Gate，等到有时钟时，也可写为时钟脉冲 CP，Clock Pulse，时钟脉冲会在 0 和 1 之间跳变，所以会每隔一段时间就可以写入）。

　　这种锁存器叫 D 锁存器，也叫门锁（因为门可以打开也可以关上）。

　　图看起来会有些绕，可以先不用往下看，先想一下。

　　真值表：

| D | WE | Q(下一状态) | 说明 |
|:-:|:-:|:----------:|:-----|
| X(无关) | 0 | Q(保持) | 保持当前状态 |
| 0 | 1 | 0 | 写入 0 |
| 1 | 1 | 1 | 写入 1 |

 **思考题 2** 

> 　　继思考题 1，D 锁存器有输出不确定的禁止状态吗？

### 锁存器的问题

　　锁存器有一个问题：它对输入信号太敏感了。只要输入变化，输出就可能变化。复杂的电路中可能会导致混乱。

　　有什么办法解决这个问题呢？

### 思考题答案（仅供参考）

#### 思考题 1

　　这个电路里 R 接在最后一级与门上，因此 R = 1 会直接把输出压成 0。即使 S 同时为 1，Q 仍是 0，所以它叫“复位优先”锁存器。标准交叉耦合 SR 锁存器的非法输入则出现在两个输入同时有效时，两个输出不再互为反相。

#### 思考题 2

　　没有。可以看一下上面的动图，无论 D 和 WE 怎么变化，D 锁存器结构中置位和复位输入都不会同时为 1，因此不会触发复位优先锁存器的竞争情况；它始终会明确地保持、写入 0 或写入 1。
