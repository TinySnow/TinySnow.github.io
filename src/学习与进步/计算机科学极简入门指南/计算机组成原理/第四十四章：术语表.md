# 术语表

## 复习

- 输入输出系统：I/O 接口连接计算机与外设，支持查询、中断和 DMA 三种方式
- 中断系统：中断让 CPU 响应外设请求，并在保存和恢复现场后继续执行程序
- 第一次呼吸：把 CPU、存储器、总线和外设合在一起，让完整计算机自动运行

## TL;DR

- 本章按主题汇总全书出现过的术语，供随时回查
- 每条只给一句话解释，想细看请回到对应章节

## 正文

### 数据与编码

| 术语 | 一句话解释 |
| :--- | :--- |
| bit（比特） | 一个二进制位，0 或 1 |
| Byte（字节） | 8 个 bit，常用大写 B 表示 |
| 二进制 / 八进制 / 十六进制 | 分别逢 2、8、16 进一的计数法，后两者是二进制的简写 |
| 原码 | 最高位当符号位，其余位是数值绝对值 |
| 反码 | 负数在原码基础上，除符号位外按位取反 |
| 补码 | 负数的反码加一，计算机表示有符号数的标准 |
| 浮点数 | 用“符号 + 阶码 + 尾数”表示小数，范围大但精度有限 |
| ASCII | 给 128 个常用字符编号的编码 |
| Unicode | 给全世界文字编号的字符集 |
| UTF-8 | Unicode 的一种变长存储方案，英文 1 字节、汉字常 3 字节 |

### 逻辑门

| 术语 | 一句话解释 |
| :--- | :--- |
| 逻辑门 | 处理 0/1 信号的最基本电路单元 |
| 与门 / 或门 / 非门 | 全 1 才 1 / 有 1 就 1 / 取反 |
| 异或门 | 两输入不同时输出 1 |
| 多路选择器（MUX） | 多个输入里选一个输出 |
| 译码器 | 把二进制码翻译成“选中某一路”的信号 |
| 真值表 | 列出所有输入组合及其输出的表格 |

### 运算器

| 术语 | 一句话解释 |
| :--- | :--- |
| 半加器 / 全加器 | 算两个一位的和 / 再考虑低位进位的加法器 |
| 进位 | 本位相加产生的、要送给高位的信号 |
| 算术逻辑单元（ALU） | 集成了加减乘除和逻辑运算的运算部件 |
| ALU 控制码 | 告诉 ALU“做哪种运算”的控制信号编码 |
| 累加器 | 能保存“当前和”、不断累加的寄存器 |
| 状态标志（ZF/SF/CF/OF） | 结果的特征位：零 / 负 / 进位 / 溢出 |

### 时序与存储

| 术语 | 一句话解释 |
| :--- | :--- |
| 锁存器 | 最简单的 1 位记忆单元 |
| 触发器 | 在指定时钟边沿采样并保存一位数据的记忆单元 |
| 时钟 | 全局节拍，规定各部件何时更新 |
| 上升沿 / 下降沿 | 信号从 0 跳 1 / 从 1 跳 0 的瞬间 |
| 寄存器 | 多个触发器并排，暂存一个字的数据 |
| 存储器 | 按地址存取的大量存储单元 |
| RAM / ROM | 可读可写、断电丢失 / 只读、断电保留 |
| SRAM / DRAM | 用触发器保存（快而贵）/ 用电容保存（慢而便宜） |
| 缓存（Cache） | CPU 旁的小而快的存储 |
| 命中 / 缺失 | 数据在不在缓存里 |
| LRU | 替换时优先淘汰最久未用的数据 |
| 缓存一致性 | 多核下保证各缓存看到同一份数据 |
| MESI | 一种缓存一致性协议 |

### 处理器

| 术语 | 一句话解释 |
| :--- | :--- |
| 指令 | “做什么 + 对谁做”的一条命令 |
| 操作码 | 指令中表示要执行哪类操作的字段 |
| 操作数 | 指令里参与运算的数据或它的位置 |
| 程序 | 一串按顺序排列的指令 |
| 程序计数器（PC） | 保存下一条指令地址的寄存器 |
| 指令寄存器（IR） | 保存当前正在执行的指令 |
| 控制器 | 按节拍产生并分发控制信号的部件 |
| 数据通路 | 数据在各部件间流动的路径 |
| 硬布线 / 微程序控制 | 用固定电路 / 用查表实现控制器 |
| 流水线 | 让多条指令的不同阶段重叠执行 |
| 冒险 | 让流水线卡壳的冲突，分数据/控制/结构三类 |
| 超标量 | 一拍发射多条指令的处理器技术 |

### 系统与外设

| 术语 | 一句话解释 |
| :--- | :--- |
| 总线 | 各部件共享的公共传输通道 |
| 地址 / 数据 / 控制总线 | 分别传地址、数据、控制信号 |
| 中断 | 外设“打断”CPU、让它先处理紧急事件 |
| 中断向量表 | 中断号到处理程序入口的对照表 |
| I/O | 输入输出，计算机与外界交换数据 |
| DMA | 外设与内存直接传数据，不经 CPU |
