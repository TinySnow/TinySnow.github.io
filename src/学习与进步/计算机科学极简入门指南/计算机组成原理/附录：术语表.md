# 术语表

## TL;DR

- 本章不再增加新零件
- 遇到忘记的名词，可以按建造顺序回来查找

## 正文

　　机器已经跑起来了。最后把一路用过的名字收进工具箱，方便以后回来翻找。

### 数据与编码

| 术语 | 一句话解释 |
| :--- | :--- |
| bit（比特） | 一个二进制位，只能是 0 或 1 |
| Byte（字节） | 8 个比特，常写作大写 B |
| 二进制 | 只使用 0 和 1、逢 2 进 1 的计数法 |
| 编码 | 约定一串比特应当怎样解释 |
| 原码 | 用一位表示正负，其余位表示绝对值 |
| 反码 | 负数的原码保留符号位，其余位取反 |
| 补码 | 负数取反加一，使加减法可以共用加法器 |
| 浮点数 | 用符号、阶码和尾数近似表示很大或很小的数 |
| ASCII / Unicode | 给字符编号的两套约定，Unicode 覆盖的文字更多 |
| UTF-8 | Unicode 的一种变长存储方式 |

### 逻辑与运算

| 术语 | 一句话解释 |
| :--- | :--- |
| 逻辑门 | 根据 0、1 输入产生 0、1 输出的基本电路 |
| 与、或、非 | 全 1 才为 1、有 1 就为 1、把输入取反 |
| 异或 | 两个输入不同时输出 1 |
| 真值表 | 列出所有输入组合及对应输出 |
| 多路选择器 | 根据选择信号，从多路输入中放行一路 |
| 译码器 | 把二进制编号展开成“选中某一路”的信号 |
| 半加器 | 把两个一位数相加，输出和与进位 |
| 全加器 | 在半加器基础上再接收低位进位 |
| ALU | 根据控制码完成算术或逻辑运算的部件 |
| 数据通路 | 数据在寄存器、ALU、存储器之间经过的路线 |
| Z / N / C / V | 零、负数、无符号进位、有符号溢出标志 |

### 记忆与节拍

| 术语 | 一句话解释 |
| :--- | :--- |
| 反馈 | 把电路输出送回输入，让过去影响现在 |
| 锁存器 | 在使能期间可写入并维持一个比特的电路 |
| 触发器 | 在指定时钟边沿采样并保存一个比特的电路 |
| 时钟 | 让各部件按统一节拍交接数据的周期信号 |
| 时序图 | 把多根信号随时间的变化画在同一横轴上 |
| 寄存器 | 多只触发器并排组成的高速多位存储 |
| 累加器 | 保存当前运算结果、供下一轮继续使用的寄存器 |
| 状态机 | 根据当前状态和输入决定动作与下一状态的电路 |
| 地址 | 给某个存储位置分配的编号 |
| RAM | 可按地址反复读写、通常断电丢失内容的存储器 |
| ROM | 用来保存不希望在日常运行中随意改变的内容 |

### 程序与处理器

| 术语 | 一句话解释 |
| :--- | :--- |
| 指令 | 机器能够执行的一条编码命令 |
| 操作码 | 指令中说明“做什么”的部分 |
| 操作数 | 指令中说明“对谁做”的部分 |
| 指令集 | 一台机器支持的指令及其编码规则 |
| 程序 | 按一定顺序排列的一串指令 |
| PC | 保存下一条指令地址的程序计数器 |
| IR | 保存当前指令的指令寄存器 |
| 控制器 | 按节拍发出控制信号的状态机 |
| CPU | 由运算器、寄存器组和控制器等组成的中央处理器 |
| 流水线 | 让多条指令同时处在不同执行阶段的技术 |

### 存储与外界

| 术语 | 一句话解释 |
| :--- | :--- |
| 存储层次 | 从少而快到多而慢排列的多级存储 |
| 缓存 | 保存近期可能再用数据的快速小容量存储 |
| 命中 / 缺失 | 所需数据在缓存中找到 / 没有找到 |
| 总线 | 多个部件共享的一组通信线路 |
| I/O | 计算机与外部世界之间的输入和输出 |
| I/O 接口 | 在总线与具体设备之间缓冲和转换的部件 |
| DMA | 让设备与主存直接批量传输数据的机制 |
| 中断 | 让 CPU 暂停当前程序、先处理某个事件的机制 |
| 中断向量表 | 从中断编号找到处理程序入口的表 |

## 小结

### 知识点

- 从数据、逻辑门、记忆到整机的核心术语
- 名词之间的顺序也是整台计算机的建造顺序
