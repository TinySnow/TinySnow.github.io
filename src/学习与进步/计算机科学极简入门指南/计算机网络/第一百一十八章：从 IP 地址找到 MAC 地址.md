# 第一百一十八章：从 IP 地址找到 MAC 地址

## TL;DR
- ARP 在 IPv4 本地网络中把下一跳 IP 地址解析为 MAC 地址。

## 正文
　　主机决定下一跳是同网目标或网关后，仍要把帧交给那个接口。它广播 ARP 请求“谁拥有这个 IP”，对应设备单播回复自己的 MAC；结果会暂存于 ARP 缓存。跨网络时，ARP 找的是网关 MAC，不是远端主机 MAC。

**思考题**
> 发往远端网站的帧为何使用网关 MAC？

## 小结
- ARP 完成 IP 路由决定落到本地链路发送的最后一步。

### 思考题答案（仅供参考）
　　远端不在本链路，当前这一跳只能先交给能继续转发的网关。
